## 已核实的原书条件与疑点

**CH06-S01，PDF 333：逆矩阵的适用条件，保留正文、不增纠错注。** 原页明确写“with solution”并给出 $x=(\bar A^T\bar A+P)^{-1}\bar A^Tb$；现译“其解为”及原式一致。此表达式要求 $M=\bar A^T\bar A+P$ 非奇异；若 M 奇异，应解正规方程 $Mx=\bar A^Tb$ 或消去共同冗余方向。已回查 PDF 305，6.1.1 确有“without loss of generality … columns … independent”的约定，因此不把此处列为确定的原书错误。PDF 332 的新随机模型没有显式重述秩条件，但适用范围可由前述约定理解。高倍率证据 `pdf-305-rank.png`、`pdf-333-inverse.png`；集成 Agent 同意仅在本审查记录留此条件，不打扰读者。

**CH06-S02，PDF 336：平方正则化的端点限制，建议简短译注。** 原页在 SOCP 后写“the solution … is the same … for some value of … δ”；对应译句“由于这个问题的解与正则化参数 δ 取某个值时的正则化最小二乘问题……的解相同”。已核完整 PDF 335–336 的范数球假设及高倍率局部 `pdf-336-regularization.png`，原文未排除零解端点。取 $\bar A=b=1,a=2$，$|x-1|+2|x|$ 的唯一最小点为 0；但任意有限 $\delta\geq0$ 下，$(x-1)^2+\delta x^2$ 的唯一最小点为 $1/(1+\delta)>0$。该端点只能在 $\delta\to\infty$ 的极限中得到。正文及两原式应保留；译注只提示某些端点需要极限参数，不将此数学解释混入原文。集成 Agent 已确认准备加注，最终注文本仍待独立验收。
