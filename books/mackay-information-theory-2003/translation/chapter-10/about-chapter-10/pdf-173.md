## 符号一览（Cast of characters）

| 符号 | 含义 |
|:---|:---|
| $Q$ | 有噪信道。 |
| $C$ | 信道容量。 |
| $X^N$ | 用来生成一个随机码的系综。 |
| $\mathcal C$ | 一个随机码。 |
| $N$ | 码字的长度。 |
| $\mathbf{x}^{(s)}$ | 一个码字，即码中的第 $s$ 个码字。 |
| $s$ | 选定码字的编号（便于记忆：信源 source 选择 $s$）。 |
| $S=2^K$ | 码中码字的总数。 |
| $K=\log_2 S$ | 若以均匀概率从 $S$ 个码字中选取一个，这次选择传达的比特数。 |
| $\mathbf{s}$ | 数字 $s$ 的二进制表示。 |
| $R=K/N$ | 码率，即每次使用信道传送的比特数（有时改记作 $R'$）。 |
| $\hat{s}$ | 解码器对 $s$ 的猜测。 |
