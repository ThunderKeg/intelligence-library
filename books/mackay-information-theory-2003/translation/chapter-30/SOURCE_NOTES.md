# 第 30 章原书排印疑点

- **PDF400，算法 30.1：**代码行 `Enew = findE ( xnew ) ;` 右侧原书注释印为 “find new value of H”。变量名和调用表明这一行计算的是新的 $E$，下一行 `Hnew = p' * p / 2 + Enew ;` 才计算新的 $H$。译稿按原注释译为「求 $H$ 的新值」，没有擅自修改代码或注释含义。
- **PDF401，算法/图的称谓：**原书上页代码的边栏标题是 “Algorithm 30.1”，但 PDF401 正文称 “The source code in figure 30.1”。译稿分别保留「算法 30.1」与「图 30.1」的原书称谓，不把后者无依据改成算法。
