# 第 45 章　高斯过程

> **编者导读（非原书正文）**　本章把回归与分类中的未知函数直接作为概率模型的对象，说明高斯过程如何用均值函数和协方差函数描述函数先验，以及如何据此作出预测。

Rumelhart、Hinton 和 Williams（1986）关于神经网络监督学习的论文发表后，人们对使用多层感知机、径向基函数等非线性参数模型，凭经验刻画高维数据中的关系产生了浓厚兴趣。按这些建模方法的贝叶斯解释，假设数据背后存在一个由参数 $\mathbf w$ 确定的非线性函数 $y(\mathbf x)$，数据为 $\{\mathbf x^{(n)},t_n\}_{n=1}^{N}$；让模型适应数据，相当于在给定数据的条件下对函数作*推断*。记输入向量集合为 $\mathbf X_N\equiv\{\mathbf x^{(n)}\}_{n=1}^{N}$，对应的目标值向量为 $\mathbf t_N\equiv\{t_n\}_{n=1}^{N}$。对 $y(\mathbf x)$ 的推断，由后验概率分布描述：

$$P(y(\mathbf x)\mid\mathbf t_N,\mathbf X_N)=\frac{P(\mathbf t_N\mid y(\mathbf x),\mathbf X_N)P(y(\mathbf x))}{P(\mathbf t_N\mid\mathbf X_N)}.\tag{45.1}$$

右边的两个因子中，第一个 $P(\mathbf t_N\mid y(\mathbf x),\mathbf X_N)$ 是给定函数 $y(\mathbf x)$ 时目标值的概率；对回归问题，通常假设它是一个可分解的高斯分布。第二个 $P(y(\mathbf x))$ 是模型假设的函数先验分布。这一先验隐含在参数模型的选择和拟合模型时所用正则化项的选择中。先验通常规定，函数 $y(\mathbf x)$ 应当连续、光滑，高频成分的功率小于低频成分；但使用参数模型后，先验的确切含义多少变得不那么清楚。

现在，预测将来的 $t$ 值时，真正起作用的只有假设的先验 $P(y(\mathbf x))$ 和噪声模型 $P(\mathbf t_N\mid y(\mathbf x),\mathbf X_N)$；函数 $y(\mathbf x;\mathbf w)$ 的参数化方式无关紧要。

高斯过程建模的思路是：不把 $y(\mathbf x)$ 参数化，而是直接在函数空间上指定先验 $P(y(\mathbf x))$。最简单的一类函数先验称为高斯过程。可以把它看作将有限维向量空间上的高斯分布推广到无限维函数空间。正如高斯分布由均值和协方差矩阵完全确定，高斯过程由均值函数和*协方差函数*确定。这里，均值是 $\mathbf x$ 的函数（我们常取零函数），协方差则是函数 $C(\mathbf x,\mathbf x')$，表示函数 $y$ 在点 $\mathbf x$ 与 $\mathbf x'$ 处的取值之间的预期协方差。在某一个具体的数据建模问题中，假设函数 $y(\mathbf x)$ 是从这一高斯分布中抽取的*单个*样本。高斯过程早已是处理各种空间和时间问题的成熟模型，例如布朗运动、朗之万过程和维纳过程都是高斯过程；广泛用于语音波形建模的卡尔曼滤波器，也对应于高斯过程模型；地质统计学中的“克里金”（kriging）方法，则是一种高斯过程回归方法。
