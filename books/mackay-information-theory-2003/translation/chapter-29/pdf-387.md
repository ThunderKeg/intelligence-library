### *切片采样的基本框架*

设我们要从 $P(x)\propto P^*(x)$ 抽样，其中 $x$ 是实数。一维切片采样算法把曲线 $P^*(x)$ 下方的二维点 $(x,u)$ 转移到同一曲线下方的另一个点 $(x',u')$，使得无论从什么初始点出发，$(x,u)$ 的概率分布都趋于曲线 $P^*(x)$ 下方面积上的均匀分布。这类似于拒绝采样（第 29.3 节）在曲线 $P^*(x)$ 下方产生的均匀分布。

一维切片采样算法的一次转移 $(x,u)\to(x',u')$ 包含以下步骤。其中第 3 步和第 8 步还需要进一步说明。

```text
1: 计算 P*(x)
2: 抽取纵坐标 u′ ~ Uniform(0, P*(x))
3: 建立一个包含 x 的水平区间 (x_l, x_r)
4: 循环 {
5:     抽取 x′ ~ Uniform(x_l, x_r)
6:     计算 P*(x′)
7:     若 P*(x′) > u′，跳出第 4–9 步的循环
8:     否则修改区间 (x_l, x_r)
9: }
```

第 3 步可以用几种方法建立区间 $(x_l,x_r)$，第 8 步也可以用几种方法修改这个区间。关键是整个方法必须满足详细平衡，使曲线 $P^*(x)$ 下方的 $(x,u)$ 的均匀分布保持不变。

### *第 3 步的“向外延伸”方法*

在建立包含 $x$ 的区间 $(x_l,x_r)$ 时，“向外延伸”方法以长度 $w$ 为步长向两边扩展，直到找到使 $P^*$ 小于 $u$ 的端点 $x_l$ 和 $x_r$。算法见图 29.16。

```text
3a: 抽取 r ~ Uniform(0, 1)
3b: x_l := x - rw
3c: x_r := x + (1-r)w
3d: 当 P*(x_l) > u′ 时 { x_l := x_l - w }
3e: 当 P*(x_r) > u′ 时 { x_r := x_r + w }
```

### *第 8 步的“收缩”方法*

每当抽出的点 $x'$ 使 $(x',u')$ 位于曲线 $P^*(x)$ 上方时，就收缩区间，让其中一个端点变为 $x'$，同时确保原来的点 $x$ 仍在区间内。

```text
8a: 若 x′ > x，则 { x_r := x′ }
8b: 否则 { x_l := x′ }
```

### *切片采样的性质*

和标准 Metropolis 方法一样，切片采样也通过随机游走移动。不过，在 Metropolis 方法中，步长的选择对推进速度至关重要；在切片采样中，步长会自行调整。如果初始区间的宽度 $w$ 比高概率区域的宽度小了 $f$ 倍，向外延伸过程就会扩大区间。向外延伸的代价仅与 $f$ 成正比；而在 Metropolis 方法中，若步长太小，计算时间与 $f$ 的平方成正比。
