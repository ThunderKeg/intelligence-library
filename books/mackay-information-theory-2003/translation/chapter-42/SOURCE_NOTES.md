# 第 42 章原书核对笔记

- PDF 524（印刷 512）§42.6 末段：原书将最速下降写成 $\mathrm d x_i/\mathrm dt\propto\partial L/\partial x_i$，并称 $\mathrm d x_i/\mathrm dt$ 与 $\partial\widetilde F/\partial x_i$ 同号。这与通常以负梯度表示最速下降的符号约定表面不一致。译文两处均照印本保留正号/“同号”，不据推导擅改；独立源审已在 300 dpi 原页复核确认。
- PDF 528（印刷 516）式 (42.28)：印本的 $-\sum_i\sum_n$ 后面没有把 $t_i^{(n)}\ln y_i^{(n)}+(1-t_i^{(n)})\ln(1-y_i^{(n)})$ 括在一起。通常的交叉熵目标函数会把两项一同置于求和及负号之内；译稿照印本保留显式排版，不擅加括号。独立源审已对高清原页复核确认。
- PDF 529→530（印刷 517→518）§42.9：原书同一句在 PDF 529 末尾停在 “corresponding”，PDF 530 开头接 “tour, plus a constant...”。中文在 `pdf-529.md` 中补足整句，避免阅读站出现以逗号悬空的独立段落；`pdf-530.md` 从下一完整句开始。
- PDF 530（印刷 518）图 42.11(b)：`pdfimages -list` 显示原书地图底图自身仅 435×535 像素、约 147 ppi，多数底图小字在 PDF 原页上也无法可靠辨认。独立源审抽出原图确认可辨 `Jesus Green`、`Coe Fen`、`The Backs`，下缘仅可见 `Sheeps`，后续不清。译稿保留整张地图及 1–30 访问点与路线，只译注能确认的标签，不猜测模糊的小地名。
