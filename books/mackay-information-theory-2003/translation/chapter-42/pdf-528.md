```octave
w = x' * x ;                # 用赫布规则初始化权重

for l = 1:L                 # 循环 L 次

    for i=1:I               #
        w(i,i) = 0 ;        # 确保自连接权重为零
    end                     #

    a  = x * w     ;        # 计算全部激活量
    y  = sigmoid(a) ;       # 计算全部输出
    e  = t - y     ;        # 计算全部误差
    gw = x' * e    ;        # 计算梯度
    gw = gw + gw'  ;        # 使梯度对称

    w = w + eta * ( gw - alpha * w ) ;  # 更新一步
endfor
```

算法 42.9　优化 Hopfield 网络权重、使其作为联想记忆工作的 Octave 源代码。参见算法 39.5。数据矩阵 `x` 有 $I$ 列、$N$ 行；矩阵 `t` 与 `x` 相同，只是其中的 $-1$ 全部改为 $0$。

因此，正如我们为训练单个分类神经元定义了目标函数 (39.11) 那样，现在可以定义

$$G(\mathbf W)=-\sum_i\sum_n t_i^{(n)}\ln y_i^{(n)}+(1-t_i^{(n)})\ln(1-y_i^{(n)})\tag{42.28}$$

其中

$$t_i^{(n)}=\begin{cases}1&x_i^{(n)}=1\\0&x_i^{(n)}=-1\end{cases}\tag{42.29}$$

并且

$$y_i^{(n)}=\frac{1}{1+\exp(-a_i^{(n)})},\quad\text{其中 }a_i^{(n)}=\sum_j w_{ij}x_j^{(n)}.\tag{42.30}$$

接着，我们可以借用为单个神经元编写的算法（算法 39.5，原书第 478 页），写出优化 Hopfield 网络的算法 42.9。Octave 的方便语法使它只需改动很少几处；增加的代码行确保所有自连接权重 $w_{ii}$ 都为零，权重矩阵也对称（$w_{ij}=w_{ji}$）。

符合预期的是，这种学习算法比一次性完成的赫布学习规则效果更好。图 42.5 的六种模式无法用赫布规则记住；改用算法 42.9 学习后，六种模式全都成为稳定状态。

## 42.9　用 Hopfield 网络求解优化问题

Hopfield 网络的动力学会最小化一个能量函数，因此自然会想到：能否把值得研究的优化问题映射到 Hopfield 网络上？生物数据处理问题通常包含*满足约束*的要求。例如，在解释场景时，我们可能希望推断每个可见元素的空间位置、朝向、亮度和纹理，还要推断哪些可见元素在物体中相互连接。这些推断受到现有数据，以及关于物体连续性的先验知识的约束。
