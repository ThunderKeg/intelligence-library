# 第 44 章原书核对笔记

- PDF 539→540（印刷 527→528）§44.1“这些网络能实现什么样的函数？”末段：原书同一句在 PDF 539 末停于“set the biases”，PDF 540 页首接“and weights ... to random values, and plot the resulting function y(x).”。译稿在 `pdf-539.md` 补足这一整句，`pdf-540.md` 从下一完整句开始，以避免网站出现独立的残句；符号与图 44.2/44.3 引用均照原页。
- PDF 542（印刷 530）式 (44.9)：印本中 $\sum_n$ 写在第一项 $t^{(n)}\ln y$ 前，第二项 $(1-t^{(n)})\ln(1-y)$ 前没有重复求和，也没有把两项一起括进求和。译稿照印本保留可见括号与求和范围，不擅改为通常写法；独立源审已在高清原页确认。
- PDF 545（印刷 533）式 (44.12)：印本一面定义 $I(T;Y)=H(T)-H(T\mid Y)$，一面将求和项的对数分数印为 $P(t)/P(t\mid y)$；这与常见互信息展开式的比值方向相反。译稿按高清原页保留 $P(t)/P(t\mid y)$，不根据推导更改原式，待独立源审确认。
