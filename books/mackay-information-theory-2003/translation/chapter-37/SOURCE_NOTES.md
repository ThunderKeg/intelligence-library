# 第 37 章原页核对记录

- PDF 物理页 473（印刷页 461）：原书正文与图 37.4 图注均写 $p_{A+}<10p_{B+}$，同时说这对应“方案 A 比方案 B 有效十倍”；原图阴影仅为左上方很窄的三角形，按坐标实际更像 $p_{A+}<p_{B+}/10$。译稿照印本保留 `10`，图资产照原页截取；这是原书正文/图示之间的疑点，未由译者擅自改式。
- PDF 物理页 475（印刷页 463）：纠错码实验一段印为推断 $\log p_b$ 的误差大致“goes roughly as $\sqrt r$”；高分辨率原页放大后确认为 $\sqrt r$，虽然通常的估计误差随 $r$ 增加应减小。译稿照印本保留，未补写倒数。
- PDF 物理页 477（印刷页 465）：式 (37.32) 的区间上下端点都印为 $\min(x_1,x_2)$。本例故意把区间构造为单点，才出现后文 $75\%$ 的覆盖率与给定数据后的 $50\%/100\%$ 后验概率对比；译稿照印本保留两个 `min`，须由独立源审再次核原页。
- PDF 物理页 478（印刷页 466）：习题 37.3 的 (b)/(c) 也分别印成 $p_{A+}<10p_{B+}$ 和 $p_{B+}<10p_{A+}$；译稿照印本保留，作为 PDF473 图 37.4 疑点的相关印本文字记录。
