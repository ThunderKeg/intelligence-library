# 第 48 章原书核对笔记

- PDF 586（印刷 574）：§48.1 和 §48.2 标题左侧均有实心三角，专属构建器须为标题保留可视标记。
- PDF 586→587（印刷 574→575）：PDF 586 末段最后的 “Because” 续至 PDF 587 图 48.1 下面的 “these filters require $k=7$ bits of memory ...”。为避免网页上出现断句，译文在 `pdf-586.md` 合成完整句，后页从下一段开始。
- PDF 591→592（印刷 579→580）：§48.4 首段最后的 “The transmitted codeword then consists of” 续至 PDF 592 的 “$K$ source bits ... rate $1/3$”。译文在 `pdf-591.md` 合为完整句，后页从下一段开始。
- PDF 592（印刷 580）：原书写 “a turbo code of smaller rate such as $1/2$” 并称它由码率 $1/3$ 的码删余得到。$1/2$ 数值上大于 $1/3$，此处“smaller rate”与数值和删余方向不协调；页稿照印本保留“码率较小”，不擅自更正。
- PDF 592→593（印刷 580→581）：停止准则一段的末句 “the low-weight codewords” 续为 “of the code, which may improve the process of code design”。译文在 `pdf-592.md` 合为完整句，后页从下一段开始。
- PDF 593（印刷 581）：§48.6 的习题 48.2 解答在印本指向“图 48.7 上面那条”，虽然习题出在 PDF 590 并配图 48.6；页稿按印本保留图 48.7，不按推测改动。
