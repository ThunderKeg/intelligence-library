# 附录 C 原书核对记录

正文唯一依据为仓库根目录原书 PDF 的物理页 617–624。下列位置在印本中有疑点或需要保留的写法，译文均按可视原页照录。

- PDF622，印刷页 610：式 (C.17) 前原书写 “equation (C.19) implies”，尽管所述展开紧接式 (C.16)，而 (C.19) 在下文才出现。译文保留原交叉引用。
- PDF623，印刷页 611：式 (C.32) 第一行印 $\lambda^{(a)}$，第二行对应项印 $\lambda^{(a)}(0)$；译文分别照录，未自行统一。
- PDF624，印刷页 612：§C.4 的各数值按 2003 年印本保留，包括当时的人口、基因组、存储容量和风险示例；这是一张原书数值对照表，译文不对数值作现代更新。
