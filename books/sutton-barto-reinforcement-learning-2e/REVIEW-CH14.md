## 问题及复核结果

### F-01 · 阻断：图 14.1、图 14.4 的图注及邻近正文在 JSON 中丢失

源稿 `page-351.md` 有完整的图 14.1 图注、图内文字译注，以及紧接的“图 14.1 展示了……”和“图 14.1 中最简单的是……”两段正文。生成的 `chapter-14.json` 中，图 14.1 的 `caption` 却成了后一段正文的开头；前两项文字不在 JSON 中，页 351 更没有 `paragraph` 块。源稿 `page-356.md` 同样有完整的图 14.4 图注、译注及后续“图 14.4 的 US 预测曲线……”段落，生成结果的 `caption` 被这段正文覆盖，原图注与正文均不在 JSON 中。仅核查 Markdown 源稿或图片能加载，无法发现这一缺漏。

原因定位：`scripts/bundle_sutton_chapters.py` 的 `FIGURE_CAPTION` 匹配图号后**没有冒号**的普通正文；只要前一块仍是同页 `figure`，解析器就把该正文当作图注并覆盖原图注。应限定图注必须有“图 14.1：”一类明确分隔符，或在成功附上图注后不再覆盖，随后重建第 14 章并断言两幅图的完整图注与相邻正文均在 JSON/网页中。

**复核：已关闭。** 构建器现仅把明确的“图 N.N：”或加粗图号标签识别为图注。重建后的图 14.1 `caption` 含“时间泛化”，图 14.4 `caption` 含“条件作用习得过程中”；原书相应图注的来源信息也在。JSON 中图 14.1 后两段正文和图 14.4 后正文分别成为独立 `paragraph`，与 PDF 内容核对一致。桌面及 390px 深色阅读页均实见图注、译注和图形。

### F-02 · 图 14.5 的图注和图内译注没有挂在图片块上

`page-365.md` 在图片后先写 `**图内文字译注：**`，再写 `**图 14.5：**`。构建器只识别不带这类加粗标记、且紧邻图片的译注与图注；现在图 14.5 的 JSON `figure` 块既没有 `caption`，也没有 `annotations`，两段文字成了普通段落。正文未丢，但图文语义结构和阅读排版有误。将图注放在图片后并使用构建器可识别的格式，再接图内译注；重建后核对 `figure.caption` 和 `figure.annotations`。同时保留原书图注中模型、回报值及版权来源的全部信息。

**复核：已关闭。** 构建器现识别加粗的图内译注及图号标签。图 14.5 的 JSON `figure` 同时含完整 `caption` 和三条 `annotations`，网页中图注在译注之前呈现；桌面显示全图，窄屏可横向查看且文字可读。与 PDF 印刷页 365 对照，迷宫、两种策略、奖励 0/4/2/3 和图注来源均保留。

### F-03 · 印刷页 361：迹条件作用的时间界限、TD 预测目标误译

PDF 物理页 383 的第 14.4 节原文为“US onset follows **CS offset** by a non-negligible time interval”；`page-361.md` 写成“条件刺激（CS）的**出现**与无条件刺激（US）的出现相隔……”，把 CS **结束**误写成 CS 开始，改变了迹间隔的定义。同页后文原文说 TD 方法可在经典条件作用类任务中提供“**immediate prediction targets**”；译文“几乎立即给出事件的预测”改变了 TD 价值函数在更新中提供即时预测**目标**的角色。建议按原书分别修正，并核对本章其他“迹间隔/预测目标”用语。

**复核：已关闭。** 现译为“US 开始之前，CS 已经结束了一段不可忽略的时间”和“立即提供预测目标”，分别对应原文的 CS offset→US onset 及 immediate prediction targets；重建 JSON 与网页正文一致。

### F-04 · 印刷页 362：同一术语两种译法

PDF 物理页 384 的两个位置均为 Hull 的 “molar stimulus traces”；`page-362.md` 先译为“整体刺激迹”，后译为“摩尔刺激迹”。后者易被误解为化学单位或分子层级。统一为同一译名，首次出现可注明英文，并在术语表和第 15 章涉及该术语处核对一致性。

**复核：已关闭。** 两处现均为“整体刺激迹”，首次出现括注原词 `molar stimulus traces`；`TERMS.md` 已记录此译名及含义。第 15 章跨章一致性仍属于全书总审查范围。

### F-05 · 印刷页 353–354：跨页的同一原书段落被拆开

PDF 物理页 375 末尾 “The TD model accounts for blocking because it is an error-correcting learning” 与物理页 376 开头 “rule like the Rescorla–Wagner model. Beyond ...” 属同一段。源稿 `page-353.md` 将首句写为一个段落，`page-354.md` 从“不过，TD 模型除了……”另起段。按照本书跨页段落归起始页的编排规则，将该段完整归于 `page-353.md`，保持图 14.2 的原有逻辑顺序。

**复核：已关闭。** `page-353.md` 已将原书整段归到起始页；JSON 中“TD 模型像……”至 Kehoe 等人的兔瞬膜实验结果为一个 `paragraph`，图 14.2 仍紧随该段。
