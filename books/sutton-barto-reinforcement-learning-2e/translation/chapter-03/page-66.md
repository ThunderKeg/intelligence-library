按同样步骤处理 \(v_*(l)\)，得到：

公式：\[v_*(l)=\max\left\{\begin{aligned}&\beta r_s-3(1-\beta)+\gamma[(1-\beta)v_*(h)+\beta v_*(l)],\\&r_w+\gamma v_*(l),\\&\gamma v_*(h)\end{aligned}\right\}.\]

对任意 \(r_s\)、\(r_w\)、α、β 和 γ，只要 0 ≤ γ < 1 且 0 ≤ α,β ≤ 1，就恰有一组 \(v_*(h)\)、\(v_*(l)\) 同时满足这两个非线性方程。

显式求解贝尔曼最优方程，是找到最优策略、从而解决强化学习问题的一种途径。然而，这样直接求解在实践中很少有用。它类似穷举搜索：向前考虑所有可能情况，计算它们发生的概率与根据预期奖励衡量的好坏。这种求解至少依赖三个在实践中很少全部成立的假设：（1）准确知道环境动态；（2）计算资源足以完成计算；（3）状态具有马尔可夫性质。对于我们感兴趣的任务，这些假设往往有一项或多项不成立，因此通常无法精确实现这一解法。例如，对双陆棋来说，第一个和第三个假设并不成问题，但第二个假设构成了严重障碍。这个游戏大约有 10²⁰ 个状态，用当今最快的计算机解出 \(v_*\) 的贝尔曼方程也要数千年；求 \(q_*\) 也一样。在强化学习中，通常必须接受近似解。

许多不同的决策方法都可以看作对贝尔曼最优方程的近似求解。例如，启发式搜索方法可以看作把式（3.19）右侧向前展开若干次，直到一定深度，形成一棵由可能情况组成的“树”，再用启发式评价函数近似“叶”节点的 \(v_*\)。（A* 等启发式搜索方法几乎总是基于回合式情形。）动态规划方法与贝尔曼最优方程的关系更为直接。许多强化学习方法也可以清楚地理解为近似求解贝尔曼最优方程，只不过用实际经历的转移，代替对预期转移的了解。后续章节将讨论多种此类方法。
