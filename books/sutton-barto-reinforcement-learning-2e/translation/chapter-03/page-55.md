这里还需要引入折扣（discounting）的概念。采用折扣时，智能体试图选择行动，使未来获得的折扣奖励之和最大。具体来说，它选择 Aₜ，以最大化预期折扣回报：

公式（3.8）：\[G_t\doteq R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}.\tag{3.8}\]

其中，参数 γ 满足 0 ≤ γ ≤ 1，称为折扣率（discount rate）。

折扣率决定未来奖励的现值：*k* 个时间步后得到的奖励，只相当于立即得到它时价值的 γᵏ⁻¹ 倍。只要奖励序列 {Rₖ} 有界，γ < 1 时式（3.8）的无限和就有有限值。若 γ = 0，智能体只关心最大化即时奖励，因此是“短视的”：它此时的目标只是在每一步学会选择 Aₜ，以最大化 Rₜ₊₁。如果每个行动恰好只影响即时奖励，而不影响未来奖励，那么短视的智能体分别最大化每一步的即时奖励，就能最大化式（3.8）。但一般而言，追求即时奖励最大可能减少以后获得奖励的机会，从而降低回报。γ 越接近 1，回报目标对未来奖励的考虑越多，智能体也就越有远见。

相邻时间步的回报具有一种关联，对强化学习理论和算法都很重要：

公式（3.9）：\[\begin{aligned}G_t&\doteq R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\gamma^3R_{t+4}+\cdots\\&=R_{t+1}+\gamma\left(R_{t+2}+\gamma R_{t+3}+\gamma^2R_{t+4}+\cdots\right)\\&=R_{t+1}+\gamma G_{t+1}.\tag{3.9}\end{aligned}\]

只要定义 \(G_T=0\)，这个关系就对所有 \(t<T\) 成立，即使任务在 \(t+1\) 时终止也一样。因此，依据奖励序列计算回报通常很容易。

还要注意，如果 γ < 1，那么即使式（3.8）的回报由无穷多项相加而成，只要奖励是非零常数，回报仍是有限的。例如，奖励恒为 +1 时：

公式（3.10）：\[G_t=\sum_{k=0}^{\infty}\gamma^k=\frac{1}{1-\gamma}.\tag{3.10}\]
