图内文字译注：BATCH TRAINING＝批量训练；RMS error, averaged over states＝对各状态求平均的均方根误差；Walks / Episodes＝随机游走次数／回合数；MC（红线）＝蒙特卡洛方法；TD（蓝线）＝TD(0)。横轴为 0–100 个回合，纵轴为 0–0.25 的 RMS 误差。

在批量训练下，恒定步长蒙特卡洛方法收敛到的 \(V(s)\)，是每次访问状态 \(s\) 后实际回报的样本平均值。从这个意义上说，这些估计是最优的：它们使训练集中实际回报的均方误差最小。因此，右图显示批量 TD 方法在对真实价值计算的均方根误差上表现更好，似乎令人意外。为什么批量 TD 能优于这个“最优”方法？答案是，蒙特卡洛方法只在一个有限的意义下最优；TD 方法则在更贴近回报预测目标的意义下最优。

**示例 6.4：由你来预测。**现在，请把自己当作一个未知马尔可夫奖励过程的回报预测者。假设你观察到以下八个回合：

| 回合 | 观测到的状态与奖励序列 |
| --- | --- |
| 1 | A，0，B，0 |
| 2 | B，1 |
| 3 | B，1 |
| 4 | B，1 |
| 5 | B，1 |
| 6 | B，1 |
| 7 | B，1 |
| 8 | B，0 |

这表示第一个回合从状态 A 开始，以奖励 0 转移到 B，然后从 B 出发以奖励 0 结束。其余七个回合更短：都从 B 开始并立即结束。给定这一批数据，你认为最好的预测是什么，也就是 \(V(A)\) 与 \(V(B)\) 的最优估计值是什么？对于 \(V(B)\)，大概人人都会同意最优值是 \(3/4\)：在八次处于状态 B 的经历中，有六次立刻以回报 1 结束，另两次立刻以回报 0 结束。

但根据这些数据，\(V(A)\) 的最优值是什么？这里有两个合理答案。一个答案是：过程每次处于 A 时，都立刻以奖励 0 转移到 B；既然我们已经认定 B 的价值是 \(3/4\)，那么 A 的价值也必定是 \(3/4\)。理解这个答案的一种方式，是先为马尔可夫过程建立模型——在本例中就是下图所示的模型——然后依据模型计算正确的估计值。在这个模型下，确实有 \(V(A)=3/4\)。这也是批量 TD(0) 给出的答案。
