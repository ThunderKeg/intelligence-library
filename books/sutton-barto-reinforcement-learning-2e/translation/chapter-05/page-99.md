**蒙特卡洛 ES（探索性起点），用于估计 \(\pi\approx\pi_*\)**

```text
初始化：
    对所有 s ∈ S，任意选取 π(s) ∈ A(s)
    对所有 s ∈ S、a ∈ A(s)，任意设定 Q(s,a) ∈ ℝ
    对所有 s ∈ S、a ∈ A(s)，令 Returns(s,a) 为空列表
无限循环（每回合一次）：
    随机选取 S₀ ∈ S、A₀ ∈ A(S₀)，使每个状态—动作对被选中的概率都大于 0
    从 S₀、A₀ 出发，按 π 生成回合：S₀,A₀,R₁,…,S_{T−1},A_{T−1},R_T
    G ← 0
    对回合中每一步，按 t = T−1,T−2,…,0 的顺序循环：
        G ← γG + R_{t+1}
        如果状态—动作对 (S_t,A_t) 未出现在此前的 S₀,A₀,S₁,A₁,…,S_{t−1},A_{t−1} 中：
            将 G 追加到 Returns(S_t,A_t)
            Q(S_t,A_t) ← average(Returns(S_t,A_t))
            π(S_t) ← arg max_a Q(S_t,a)
```

**习题 5.4** 蒙特卡洛 ES 的伪代码效率不高，因为它为每个状态—动作对保存所有回报的列表，还反复计算这些回报的均值。更高效的做法是使用与第 2.4 节类似的技术，对每个状态—动作对只保存均值和计数，并增量更新。请说明应怎样修改伪代码。 □

在蒙特卡洛 ES 中，不论观察到回报时执行的是哪个策略，每个状态—动作对的所有回报都会被汇集起来求平均。很容易看出，蒙特卡洛 ES 不可能收敛到任何次优策略：如果它收敛到了某个次优策略，价值函数最终就会收敛到该策略的价值函数，而这又会促使策略改变。只有当策略和价值函数都达到最优时，系统才会稳定。随着动作价值函数的改变量逐渐缩小，收敛到这个最优不动点似乎不可避免，但至今尚无形式化证明。我们认为，这是强化学习中最根本的开放理论问题之一（关于一个部分解，参见 Tsitsiklis，2002）。

**例 5.3：求解二十一点。**将蒙特卡洛 ES 用于二十一点很直接。由于所有回合都是模拟游戏，很容易安排覆盖所有可能情况的探索性起点。这里，只要以相同概率随机选取庄家的牌、玩家的点数总和，以及玩家是否有可用的 A 即可。初始策略采用上一个二十一点例子评估的策略，即只在 20 或 21 点时停牌。初始动作价值函数可以在所有状态—动作对上设为零。图 5.2 给出了蒙特卡洛 ES 找到的二十一点最优策略。除“有可用的 A”策略图最左侧的一个凹口外，它与 Thorp（1966）的“基本”策略相同；Thorp 的策略中没有这个凹口。我们不确定差异的原因，但确信图中所示确实是我们所描述版本的二十一点游戏的最优策略。
