**异策略 MC 控制，用于估计 \(\pi\approx\pi_*\)**

```text
初始化，对所有 s ∈ S、a ∈ A(s)：
    任意设定 Q(s,a) ∈ ℝ
    C(s,a) ← 0
    π(s) ← arg max_a Q(s,a)    （并列时采用一致的规则）
无限循环（每回合一次）：
    b ← 任意软策略
    按 b 生成回合：S₀,A₀,R₁,…,S_{T−1},A_{T−1},R_T
    G ← 0
    W ← 1
    对回合中每一步，按 t=T−1,T−2,…,0 的顺序循环：
        G ← γG + R_{t+1}
        C(S_t,A_t) ← C(S_t,A_t) + W
        Q(S_t,A_t) ← Q(S_t,A_t) + [W/C(S_t,A_t)][G−Q(S_t,A_t)]
        π(S_t) ← arg max_a Q(S_t,a)    （并列时采用一致的规则）
        如果 A_t ≠ π(S_t)，退出本轮循环（进入下一回合）
        W ← W · 1/b(A_t|S_t)
```

这个方法有一个潜在问题：只有当回合剩余部分的所有行动都是贪心行动时，它才能从回合尾部学习。如果非贪心行动很常见，学习就会缓慢，尤其是对于出现在长回合前段的状态，学习可能大幅放慢。我们对异策略蒙特卡洛方法的使用经验还不足以判断这个问题究竟有多严重。如果问题确实严重，最重要的解决办法很可能是引入时序差分学习，这是下一章发展的算法思想。或者，当 γ 小于 1 时，下一节介绍的思路也可能带来明显帮助。
