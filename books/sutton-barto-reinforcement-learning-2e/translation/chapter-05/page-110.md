**异策略 MC 预测（策略评估），估计 \(Q\approx q_\pi\)**

```text
输入：任意目标策略 π
初始化，对所有 s ∈ S、a ∈ A(s)：
    任意设定 Q(s,a) ∈ ℝ
    C(s,a) ← 0
无限循环（每回合一次）：
    b ← 任意覆盖 π 的策略
    按 b 生成回合：S₀,A₀,R₁,…,S_{T−1},A_{T−1},R_T
    G ← 0
    W ← 1
    对回合中每一步，按 t=T−1,T−2,…,0 的顺序循环，直到 W=0：
        G ← γG + R_{t+1}
        C(S_t,A_t) ← C(S_t,A_t) + W
        Q(S_t,A_t) ← Q(S_t,A_t) + [W/C(S_t,A_t)][G−Q(S_t,A_t)]
        W ← W · π(A_t|S_t)/b(A_t|S_t)
```

## 5.7 异策略蒙特卡洛控制

现在可以介绍本书讨论的第二类学习型控制方法——异策略方法的一个例子。回想一下，同策略方法的特点是：一边使用某策略进行控制，一边估计该策略的价值。异策略方法将这两种功能分开。用于生成行为的行为策略，实际上可以与被评估和改进的目标策略完全无关。这样分开的一个好处是：目标策略可以是确定性的（例如贪心策略），而行为策略仍可持续采样所有可能行动。

异策略蒙特卡洛控制方法采用前两节介绍的一种技术。它们遵循行为策略行动，同时学习并改进目标策略。这些技术要求行为策略以非零概率选择目标策略可能选择的每个行动，即满足覆盖条件。为了探索所有可能性，还要求行为策略是软策略（也就是在所有状态下以非零概率选择所有行动）。

下一页的方框给出一种基于 GPI 和加权重要性采样的异策略蒙特卡洛控制方法，用于估计 \(\pi_*\) 和 \(q_*\)。目标策略 \(\pi\approx\pi_*\) 是相对于 Q 的贪心策略，而 Q 是 \(q_\pi\) 的估计。行为策略 b 可以是任何策略；但为保证 π 收敛到最优策略，必须为每个状态—动作对取得无穷多个回报。选择 ε-软策略作为 b 可以保证这一点。虽然行动是按另一个软策略 b 选择的，而且 b 甚至可能在回合之间或回合内部变化，但 π 仍会在所有遇到的状态上收敛到最优。
