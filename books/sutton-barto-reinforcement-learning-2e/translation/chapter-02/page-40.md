因此，只需证明前面假定的等式 ∂πₜ(x)／∂Hₜ(a) = πₜ(x)[𝟙{a = x} − πₜ(a)]。先回顾标准的求导商法则：

公式：∂[f(x)／g(x)]／∂x = { [∂f(x)／∂x]g(x) − f(x)[∂g(x)／∂x] }／g(x)²。

利用它，可写出：

公式：∂πₜ(x)／∂Hₜ(a) = [∂／∂Hₜ(a)]πₜ(x)

公式：= [∂／∂Hₜ(a)]{e^{Hₜ(x)}／[∑ᵧ₌₁ᵏ e^{Hₜ(y)}]}

公式：= { [∂e^{Hₜ(x)}／∂Hₜ(a)]∑ᵧ₌₁ᵏ e^{Hₜ(y)} − e^{Hₜ(x)}[∂(∑ᵧ₌₁ᵏ e^{Hₜ(y)})／∂Hₜ(a)] }／[∑ᵧ₌₁ᵏ e^{Hₜ(y)}]²（由求导商法则）

公式：= { 𝟙{a = x}e^{Hₜ(x)}∑ᵧ₌₁ᵏ e^{Hₜ(y)} − e^{Hₜ(x)}e^{Hₜ(a)} }／[∑ᵧ₌₁ᵏ e^{Hₜ(y)}]²（因为 ∂eˣ／∂x = eˣ）

公式：= 𝟙{a = x}e^{Hₜ(x)}／[∑ᵧ₌₁ᵏ e^{Hₜ(y)}] − e^{Hₜ(x)}e^{Hₜ(a)}／[∑ᵧ₌₁ᵏ e^{Hₜ(y)}]²

公式：= 𝟙{a = x}πₜ(x) − πₜ(x)πₜ(a)

公式：= πₜ(x)[𝟙{a = x} − πₜ(a)]。证毕。

我们已经证明，梯度赌博机算法的期望更新等于预期奖励的梯度，因此该算法是随机梯度上升的一个实例。这使我们确信它具有稳健的收敛性质。

注意，我们对奖励基线只要求它不依赖于所选行动，并不要求其他性质。例如，把基线设成零或者 1000，该算法仍是随机梯度上升的一个实例。基线的选取不影响算法的期望更新，却会影响更新的方差，从而影响收敛速度（图 2.5 就展示了这一点）。把它设为奖励的平均值也许不是最好的选择，但这种做法简单，而且实践效果良好。
