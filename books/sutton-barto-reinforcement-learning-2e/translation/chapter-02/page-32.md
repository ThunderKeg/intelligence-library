下面的方框给出了一个完整赌博机算法的伪代码；该算法以增量方式计算样本平均值，并使用 ε-贪心行动选择。我们假定函数 bandit(a) 接收一个行动，并返回相应的奖励。

**一个简单的赌博机算法**

```text
对于 a = 1, …, k，初始化：
    Q(a) ← 0
    N(a) ← 0
无限循环：
    以概率 1−ε 令 A ← argmaxₐ Q(a)（并列时随机选择）；
    以概率 ε 令 A ← 一个随机行动。
    R ← bandit(A)
    N(A) ← N(A) + 1
    Q(A) ← Q(A) + [1/N(A)] [R − Q(A)]
```

## 2.5 跟踪非平稳问题

前面讨论的平均方法适用于平稳赌博机问题，也就是奖励概率不随时间变化的赌博机问题。正如前文所说，我们经常遇到实际上非平稳的强化学习问题。在这种情况下，近期奖励应比久远的奖励获得更大的权重。最常用的办法之一是使用恒定的步长参数。例如，把用于更新前 *n*−1 个奖励的平均值 Qₙ 的增量更新规则（2.3）改为：

公式（2.5）：Qₙ₊₁ ≔ Qₙ + α[Rₙ − Qₙ]。

这里的步长参数 α ∈ (0, 1] 为常数。这样，Qₙ₊₁ 就成为过去奖励与初始估计值 Q₁ 的加权平均：

公式：Qₙ₊₁ = Qₙ + α[Rₙ − Qₙ]

公式：= αRₙ + (1−α)Qₙ

公式：= αRₙ + (1−α)[αRₙ₋₁ + (1−α)Qₙ₋₁]

公式：= αRₙ + (1−α)αRₙ₋₁ + (1−α)²Qₙ₋₁

公式：= αRₙ + (1−α)αRₙ₋₁ + (1−α)²αRₙ₋₂ + ··· + (1−α)ⁿ⁻¹αR₁ + (1−α)ⁿQ₁

公式（2.6）：= (1−α)ⁿQ₁ + ∑ᵢ₌₁ⁿ α(1−α)ⁿ⁻ⁱRᵢ。
