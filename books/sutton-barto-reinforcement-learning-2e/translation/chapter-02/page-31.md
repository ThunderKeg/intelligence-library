为了简化记号，我们只关注一个行动。现在，令 Rᵢ 表示第 *i* 次选择这个行动后得到的奖励，令 Qₙ 表示该行动被选择 *n*−1 次后的价值估计。于是可以简写为：

公式：Qₙ ≔ (R₁ + R₂ + ··· + Rₙ₋₁)／(n−1)。

一种直观的实现方式，是保存所有奖励，并在需要估计值时执行这项计算。然而，这样一来，随着得到的奖励越来越多，内存和计算需求也会持续增长。每增加一个奖励，就需要额外的空间保存它，也需要额外的计算来求分子中的和。

你可能已经想到，其实不必如此。我们很容易设计出增量式公式，使每个新奖励只需少量且恒定的计算即可更新平均值。给定 Qₙ 和第 *n* 个奖励 Rₙ，全部 *n* 个奖励的新平均值可以按以下步骤计算：

公式：Qₙ₊₁ = (1/n) ∑ᵢ₌₁ⁿ Rᵢ

公式：= (1/n)(Rₙ + ∑ᵢ₌₁ⁿ⁻¹ Rᵢ)

公式：= (1/n)(Rₙ + (n−1)[(1/(n−1)) ∑ᵢ₌₁ⁿ⁻¹ Rᵢ])

公式：= (1/n)(Rₙ + (n−1)Qₙ)

公式：= (1/n)(Rₙ + nQₙ − Qₙ)

公式（2.3）：= Qₙ + (1/n)[Rₙ − Qₙ]。

这一公式对 *n* = 1 也成立，此时 Q₂ = R₁，与 Q₁ 取什么值无关。这种实现只需存储 Qₙ 和 *n*，每得到一个新奖励时只需按式（2.3）做少量计算。

更新规则（2.3）具有一种在本书中会反复出现的形式。一般形式为：

公式（2.4）：NewEstimate ← OldEstimate + StepSize[Target − OldEstimate]。

其中，“目标 − 旧估计值”是估计误差。朝“目标”走一步可以减小这个误差。我们假定目标指出了一个值得前进的方向，尽管它可能带有噪声。例如，在上述情况中，目标就是第 *n* 个奖励。

注意，增量方法（2.3）所用的步长参数（StepSize）随时间步变化。处理行动 *a* 的第 *n* 个奖励时，该方法使用的步长参数是 1/n。本书用 α 表示步长参数，更一般地，用 αₜ(a) 表示它。
