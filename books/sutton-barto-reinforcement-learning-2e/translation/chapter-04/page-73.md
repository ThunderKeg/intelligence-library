# 第 4 章 动态规划

> 导读：本章从已知环境模型出发，说明怎样计算策略的价值、改进策略，以及反复交替这两步来求最优策略。随后介绍价值迭代、异步更新和广义策略迭代，重点是把贝尔曼方程变成可执行的更新规则。

动态规划（dynamic programming，DP）是指一类算法：只要拥有以马尔可夫决策过程（MDP）表示的完整环境模型，就能用它们计算最优策略。经典 DP 算法假设模型完全准确，而且计算成本很高，所以在强化学习中的直接用途有限；但它们在理论上仍很重要。DP 为理解本书其余部分的方法提供了必要基础。实际上，这些方法都可以看作是在不假设拥有完整环境模型、且使用较少计算的情况下，努力达到与 DP 大体相同的效果。

从本章开始，我们通常假设环境是有限 MDP：状态集 \(\mathcal S\)、动作集 \(\mathcal A\) 和奖励集 \(\mathcal R\) 都是有限的；对每个 \(s\in\mathcal S\)、\(a\in\mathcal A(s)\)、\(r\in\mathcal R\) 和 \(s'\in\mathcal S^+\)，环境动力学由概率 \(p(s',r\mid s,a)\) 给出。若任务是回合式的，\(\mathcal S^+\) 就是在 \(\mathcal S\) 中加入终止状态。DP 的思想也能用于连续状态和动作空间，但只有特殊情况才有精确解。处理连续状态和动作任务的一种常见近似办法是先把状态、动作空间离散化，再应用有限状态 DP 方法。第二部分将研究能用于连续问题的方法，它们显著扩展了这种办法。

DP 和一般强化学习的核心思想，都是用价值函数组织和引导对好策略的搜索。本章说明怎样用 DP 计算第 3 章定义的价值函数。正如那里所讨论的，一旦求得满足贝尔曼最优方程的最优价值函数 \(v_*\) 或 \(q_*\)，就容易得到最优策略：

\[
\begin{aligned}
v_*(s)
&=\max_a\mathbb E[R_{t+1}+\gamma v_*(S_{t+1})\mid S_t=s,A_t=a]\\
&=\max_a\sum_{s',r}p(s',r\mid s,a)\bigl[r+\gamma v_*(s')\bigr].
\end{aligned}\tag{4.1}
\]

或者

\[
\begin{aligned}
q_*(s,a)
&=\mathbb E\!\left[R_{t+1}+\gamma\max_{a'}q_*(S_{t+1},a')\mid S_t=s,A_t=a\right]\\
&=\sum_{s',r}p(s',r\mid s,a)\left[r+\gamma\max_{a'}q_*(s',a')\right].
\end{aligned}\tag{4.2}
\]
