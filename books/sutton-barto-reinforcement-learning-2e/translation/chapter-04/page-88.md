对于状态空间很大的问题，人们通常更愿意采用异步 DP。同步方法即使只做一次完整扫描，也需要为每个状态付出计算量和内存。有些问题甚至承担不起这点成本，却仍可能求解，因为最优求解轨迹上出现的状态相对很少。此时可以应用异步方法和其他 GPI 变体，找到好策略或最优策略的速度可能比同步方法快得多。

## 4.8 小结

本章介绍了用于求解有限 MDP 的动态规划基本思想和算法。**策略评估**是计算给定策略价值函数的过程，通常以迭代方式进行。**策略改进**是利用该策略的价值函数，计算一个改进后的策略。把两种计算结合起来，就得到最常用的两种 DP 方法：**策略迭代**和**价值迭代**。只要完整掌握有限 MDP 的模型，二者都能可靠地计算最优策略和最优价值函数。

经典 DP 方法扫描状态集，对每个状态执行一次期望更新。每次更新根据该状态所有可能的后继状态及其出现概率，更新此状态的价值。期望更新与贝尔曼方程紧密相关：几乎就是把贝尔曼方程改成赋值语句。当更新不再造成任何价值变化，得到的价值就满足对应的贝尔曼方程，也就是已收敛。正如有四种主要价值函数 \(v_\pi,v_*,q_\pi,q_*\)，相应地也有四种贝尔曼方程和四种期望更新。回溯图给出了理解 DP 更新的一种直观方式。

从**广义策略迭代**（GPI）的角度看 DP，乃至几乎所有强化学习方法，都有助于理解它们。GPI 的基本思想是两个过程围绕一个近似策略和一个近似价值函数相互作用。一个过程把策略视为给定，执行某种形式的策略评估，使价值函数更接近该策略的真实价值函数。另一个过程把价值函数视为给定，执行某种形式的策略改进；假设该价值函数就是策略的价值函数，进而使策略变得更好。虽然每个过程都会改变另一个过程赖以工作的基础，但总体上它们共同寻找一个联合解：任何一方都不能再改变的策略和价值函数，因此二者最优。有些情况下可以证明 GPI 收敛，特别是本章介绍的经典 DP 方法。其他情况下，虽然尚未证明收敛，GPI 的思想仍有助于理解方法。

DP 不一定需要完整扫描状态集。异步 DP 是原地迭代方法，可以按任意顺序更新状态；顺序甚至可能由随机过程决定，而且更新时可以使用尚未刷新的信息。这些方法中有许多可看作粒度更细的 GPI。
