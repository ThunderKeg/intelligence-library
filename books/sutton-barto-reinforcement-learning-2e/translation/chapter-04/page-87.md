## 4.7 动态规划的效率

DP 对非常大的问题也许不实用，但与其他求解 MDP 的方法相比，实际上相当高效。略去若干技术细节，在最坏情况下，DP 找到最优策略所需的时间，是状态数和动作数的多项式函数。若状态数为 \(n\)、动作数为 \(k\)，这意味着某个 DP 方法所需的计算操作数小于 \(n\) 与 \(k\) 的某个多项式函数。虽然确定性策略的总数是 \(k^n\)，DP 仍能保证在多项式时间内找到最优策略。从这个意义上说，DP 比任何直接在策略空间中搜索的方法都具有指数级的速度优势——后者若要给出同样保证，就必须穷尽检查每个策略。线性规划也能求解 MDP，而且在某些情况下，其最坏收敛保证优于 DP；但线性规划通常在比 DP 小得多的状态规模上就变得不切实际（大约相差 100 倍）。对最大规模的问题，只有 DP 可行。

有人认为 DP 的适用范围受**维度灾难**（curse of dimensionality）限制：状态数常常随着状态变量个数呈指数增长。大的状态集确实会带来困难，但这是问题本身固有的困难，不是 DP 作为求解方法特有的缺陷。实际上，与直接搜索、线性规划等竞争方法相比，DP 更适合处理大的状态空间。

在实践中，使用当今的计算机，DP 可以求解有数百万个状态的 MDP。策略迭代和价值迭代都很常用，目前并不清楚总体而言哪个更好。在实际应用中，它们的收敛速度通常比理论上的最坏运行时间快得多，尤其是在初始价值函数或策略选得好时。
