最后，再指出 DP 方法的一个特殊性质。它们都根据后继状态价值的估计，更新当前状态价值的估计。也就是说，它们用其他估计值来更新估计值。我们把这一一般思想称为**自举**（bootstrapping）。许多强化学习方法也会自举，包括那些不像 DP 那样需要完整、准确环境模型的方法。下一章将讨论既不需要模型、也不自举的强化学习方法；再下一章将讨论不需要模型、但会自举的方法。这些关键特征和性质可以分开，也可以用有趣的方式组合。

## 文献与历史评注

“动态规划”一词来自 Bellman（1957a），他说明这类方法可以用于广泛的问题。许多著作详述了 DP，包括 Bertsekas（2005，2012）、Bertsekas 和 Tsitsiklis（1996）、Dreyfus 和 Law（1977）、Ross（1983）、White（1969），以及 Whittle（1982，1983）。本书只关注用 DP 求解 MDP，但 DP 也能用于其他类型的问题。Kumar 和 Kanal（1988）从更一般的角度考察了 DP。

据我们所知，Minsky（1961）在评论 Samuel 的跳棋程序时，首次将 DP 与强化学习联系起来。Minsky 在脚注中提到，如果 Samuel 的回溯过程能用封闭的解析形式处理，就可以把 DP 用于那类问题。这句话或许使人工智能研究者误以为 DP 仅适用于可解析处理的问题，因此与人工智能大体无关。Andreae（1969）在强化学习的语境中提到了 DP。Werbos（1977）提出了一种近似 DP 的方法，称为“启发式动态规划”；它强调针对连续状态问题的梯度下降方法（Werbos，1982、1987、1988、1989、1992）。这些方法与本书讨论的强化学习算法密切相关。Watkins（1989）明确将强化学习与 DP 联系起来，把一类强化学习方法称为“增量式动态规划”。

**4.1–4.4** 这些节介绍的是成熟的 DP 算法，上述任何一本一般性 DP 参考书都会涉及。策略改进定理和策略迭代算法分别源于 Bellman（1957a）和 Howard（1960）。我们的论述受到 Watkins（1989）关于策略改进的局部视角影响。关于“价值迭代是截断策略迭代的一种形式”的讨论，基于 Puterman 和 Shin（1978）的方法。他们提出一类称为**修正策略迭代**（modified policy iteration）的算法，以策略迭代和价值迭代为两个特例。Bertsekas（1987）分析了怎样使价值迭代在有限时间内找到最优策略。

迭代式策略评估是求解线性方程组的一种经典逐次近似算法。使用两个数组、一个保留旧价值而另一个接受更新的版本，常称为 **Jacobi 式算法**，得名于 Jacobi 对这一方法的经典应用。有时它也称为**同步算法**：它产生的效果仿佛所有价值同时更新。第二个数组是顺序计算时模拟这种并行计算所必需的。原地更新的版本常称为 **Gauss–Seidel 式算法**，得名于经典的 Gauss–Seidel 线性方程组求解算法。除迭代式策略评估外，其他 DP 算法也可以按这些不同方式实现。Bertsekas 和 Tsitsiklis（1989）对这些变体及其性能差异有很好的论述。
