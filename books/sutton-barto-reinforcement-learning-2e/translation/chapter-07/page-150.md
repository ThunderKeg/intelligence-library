n 步期望 Sarsa 的异策略版本仍使用上面的 n 步 Sarsa 更新，但重要性采样比率少一个因子。也就是说，式（7.11）应使用 \(\rho_{t+1:t+n-1}\)，而非 \(\rho_{t+1:t+n}\)；当然，还要使用期望 Sarsa 的 n 步回报（7.7）。原因是期望 Sarsa 在最后一个状态考虑所有可能行动；实际选中的那个行动不会影响目标，也就无需校正。

## 7.4 ＊逐决策方法与控制变量

上一节的多步异策略方法简单、概念清楚，但可能并非最有效率。更精细的方法会使用 5.9 节介绍的逐决策重要性采样思想。为了理解这一方法，首先注意，普通 n 步回报（7.1）与所有回报一样，都可以递归地写出。对于在界限 \(h\) 结束的 n 步，回报可写为：

公式（7.12）：\(G_{t:h}=R_{t+1}+\gamma G_{t+1:h},\qquad t<h<T\)。

其中 \(G_{h:h}\doteq V_{h-1}(S_h)\)。（回想一下，这个回报在时刻 \(h\) 使用，前面记为 \(t+n\)。）现在考虑行为策略 \(b\) 不同于目标策略 \(\pi\) 时的影响。由此得到的全部经验，包括第一项奖励 \(R_{t+1}\) 和下一状态 \(S_{t+1}\)，都必须按时刻 \(t\) 的重要性采样比率 \(\rho_t=\pi(A_t\mid S_t)/b(A_t\mid S_t)\) 加权。人们可能想直接给上式右侧加权，但还可以做得更好。假设时刻 \(t\) 的行动在 \(\pi\) 下绝不会被选择，则 \(\rho_t=0\)。简单加权会使 n 步回报为零；把它用作目标时，可能造成很高的方差。这种更精细的方法改用另一种以界限 \(h\) 结束的异策略 n 步回报定义：

公式（7.13）：\(G_{t:h}\doteq\rho_t\bigl(R_{t+1}+\gamma G_{t+1:h}\bigr)+(1-\rho_t)V_{h-1}(S_t),\qquad t<h<T\)。

仍令 \(G_{h:h}\doteq V_{h-1}(S_h)\)。在这一方法中，如果 \(\rho_t=0\)，目标就与当前估计相同，不会改变估计，而不会像目标为零那样使估计缩小。重要性采样比率为零表示应忽略这个样本，因此让估计保持不变是恰当的。式（7.13）的第二个附加项称为控制变量（control variate，缘由并不直观）。注意，控制变量不改变期望更新：重要性采样比率的期望为 1（见 5.9 节），且与估计不相关，因此控制变量的期望为零。还要注意，异策略定义（7.13）严格概括了先前同策略的 n 步回报定义（7.1）；在同策略情形下，\(\rho_t\) 恒为 1，两者相同。

对于常规 n 步方法，与式（7.13）配合的学习规则是 n 步 TD 更新（7.2）。除了回报中已经包含的比率，不再显式使用其他重要性采样比率。
