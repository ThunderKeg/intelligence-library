# 第 7 章 n 步自举

> 导读：本章把蒙特卡洛方法与一步时序差分方法放在同一条谱系中，用 n 步回报控制采样奖励与自举估计的比例。先讨论状态价值预测，再依次推导 Sarsa、异策略学习、树备份及统一的 n 步 Q(σ) 算法。

本章将前两章介绍的蒙特卡洛（MC）方法与一步时序差分（TD）方法统一起来。MC 方法和一步 TD 方法都不是始终最好的。本章介绍的 n 步 TD 方法概括了两者，使我们能按照具体任务的需要，在两者之间平滑地调整。n 步方法构成一条谱系，一端是 MC 方法，另一端是一步 TD 方法。最好的方法往往位于两个极端之间。

从另一个角度看，n 步方法的好处是使我们摆脱单个时间步的束缚。在一步 TD 方法中，同一个时间步既决定行动能够多频繁地改变，也决定自举所跨越的时间间隔。在许多应用中，我们希望很快就能更新行动，以考虑发生的任何变化；但如果自举跨越的时间足以发生明显且可辨认的状态变化，效果会更好。一步 TD 方法的这两个时间间隔相同，因此必须作出折中。n 步方法允许自举跨越多个时间步，使我们摆脱单个时间步的束缚。

n 步方法的思想通常被用来引入资格迹（eligibility traces，第 12 章）的算法思想；资格迹允许同时在多个时间间隔上自举。这里我们先单独讨论 n 步自举，把资格迹机制留到后面。这样可以更好地区分问题，并尽量在较简单的 n 步设置下讨论它们。

与前面一样，我们先研究预测问题，再研究控制问题。也就是说，先研究对于固定策略，n 步方法如何帮助我们把回报预测为状态的函数，即估计 \(v_\pi\)；然后把这些思想扩展到动作价值和控制方法。
