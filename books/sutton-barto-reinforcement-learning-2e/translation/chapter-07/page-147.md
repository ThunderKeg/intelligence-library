**算法：用于估计 \(Q\approx q_*\) 或 \(q_\pi\) 的 n 步 Sarsa**

```text
对所有 s ∈ 𝒮、a ∈ 𝒜，任意初始化 Q(s,a)
把 π 初始化为相对于 Q 的 ε-贪心策略，或初始化为给定的固定策略
算法参数：步长 α ∈ (0,1]；较小的 ε > 0；正整数 n
所有对 Sₜ、Aₜ、Rₜ 的存取操作，都可以按模 n+1 的下标进行

对每个回合循环：
    初始化并存储非终止状态 S₀
    选择并存储行动 A₀ ~ π(·|S₀)
    T ← ∞
    对 t = 0,1,2,… 循环：
        如果 t < T：
            执行行动 Aₜ
            观察并存储下一奖励 Rₜ₊₁ 和下一状态 Sₜ₊₁
            如果 Sₜ₊₁ 是终止状态，则 T ← t+1
            否则，选择并存储行动 Aₜ₊₁ ~ π(·|Sₜ₊₁)
        τ ← t−n+1  （τ 是当前要更新其估计的时刻）
        如果 τ ≥ 0：
            G ← ∑ᵢ₌τ₊₁^min(τ+n,T) γⁱ⁻τ⁻¹ Rᵢ
            如果 τ+n < T，则 G ← G + γⁿQ(Sτ₊ₙ,Aτ₊ₙ)  （Gτ:τ+n）
            Q(Sτ,Aτ) ← Q(Sτ,Aτ) + α[G−Q(Sτ,Aτ)]
            如果正在学习 π，则保证 π(·|Sτ) 相对于 Q 为 ε-贪心
    直到 τ = T−1
```
