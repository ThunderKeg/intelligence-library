## 7.1 n 步 TD 预测

蒙特卡洛方法和 TD 方法之间还有哪些方法？考虑利用遵循策略 \(\pi\) 生成的样本回合来估计 \(v_\pi\)。蒙特卡洛方法根据从某状态直到回合结束所观察到的全部奖励序列，更新该状态的估计。一步 TD 方法则只利用下一项奖励，并以一步后状态的价值进行自举，代替其余奖励。因此，一种中间方法可以使用介于两者之间的奖励数目：多于一项，但少于终止前的全部奖励。例如，两步更新依据前两项奖励，以及两步后状态的估计价值。类似地，还可以进行三步、四步等更新。图 7.1 给出了估计 \(v_\pi\) 的 n 步更新谱系的备份图：左端是一步 TD 更新，右端是一直延伸到终止时的蒙特卡洛更新。

使用 n 步更新的方法仍属于 TD 方法，因为它们仍依据先前估计与后来估计之间的差异，改变先前估计。只是后来的估计不再晚一步，而是晚 n 步。时间差跨越 n 步的方法称为 n 步 TD 方法。上一章介绍的 TD 方法全都采用一步更新，所以我们称它们为一步 TD 方法。
