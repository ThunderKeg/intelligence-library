若 \(h<T\)，递归以 \(G_{h:h}\doteq Q_{h-1}(S_h,A_h)\) 结束；若 \(h=T\)，则以 \(G_{T-1:T}\doteq R_T\) 结束。随后使用不带重要性采样比率的早先 n 步 Sarsa 更新（7.5），而非式（7.11），因为比率现在已包含在 n 步回报中。完整算法如下。

**算法：用于估计 \(Q\approx q_*\) 或 \(q_\pi\) 的异策略 n 步 Q(σ)**

```text
输入：任意行为策略 b，且对所有 s ∈ 𝒮、a ∈ 𝒜 都有 b(a|s) > 0
对所有 s ∈ 𝒮、a ∈ 𝒜，任意初始化 Q(s,a)
把 π 初始化为相对于 Q 的贪心策略，或令其为给定的固定策略
算法参数：步长 α ∈ (0,1]；正整数 n
所有存取操作都可以按模 n+1 的下标进行

对每个回合循环：
    初始化并存储非终止状态 S₀
    选择并存储行动 A₀ ~ b(·|S₀)
    T ← ∞
    对 t = 0,1,2,… 循环：
        如果 t < T：
            执行行动 Aₜ；观察并存储下一奖励 Rₜ₊₁ 和状态 Sₜ₊₁
            如果 Sₜ₊₁ 是终止状态，则 T ← t+1
            否则：
                选择并存储行动 Aₜ₊₁ ~ b(·|Sₜ₊₁)
                选择并存储 σₜ₊₁
                将 π(Aₜ₊₁|Sₜ₊₁)/b(Aₜ₊₁|Sₜ₊₁) 存为 ρₜ₊₁
        τ ← t−n+1  （τ 是当前要更新其估计的时刻）
        如果 τ ≥ 0：
            如果 t+1 < T，则 G ← Q(Sₜ₊₁,Aₜ₊₁)
            对 k 从 min(t+1,T) 递减至 τ+1：
                如果 k = T，则 G ← R_T
                否则：
                    V̄ ← ∑ₐπ(a|Sₖ)Q(Sₖ,a)
                    G ← Rₖ + γ[σₖρₖ+(1−σₖ)π(Aₖ|Sₖ)]·[G−Q(Sₖ,Aₖ)] + γV̄
            Q(Sτ,Aτ) ← Q(Sτ,Aτ) + α[G−Q(Sτ,Aτ)]
            如果正在学习 π，则保证 π(·|Sτ) 相对于 Q 为贪心
    直到 τ = T−1
```
