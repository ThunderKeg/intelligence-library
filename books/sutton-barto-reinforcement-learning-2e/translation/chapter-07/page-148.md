**习题 7.4：**证明 Sarsa 的 n 步回报（7.4）可以严格写成一种新的 TD 误差之和：

公式（7.6）：\(G_{t:t+n}=Q_{t-1}(S_t,A_t)+\sum_{k=t}^{\min(t+n,T)-1}\gamma^{k-t}\bigl[R_{k+1}+\gamma Q_k(S_{k+1},A_{k+1})-Q_{k-1}(S_k,A_k)\bigr]\)。

期望 Sarsa 又如何？其 n 步版本的备份图位于图 7.3 最右侧。它与 n 步 Sarsa 一样，由采样得到的行动和状态线性串成；唯一不同的是，末端对所有可能行动分支，并照常按它们在策略 π 下出现的概率加权。除重新定义 n 步回报外，这个算法可用上面的 n 步 Sarsa 更新式描述：

公式（7.7）：\(G_{t:t+n}\doteq R_{t+1}+\cdots+\gamma^{n-1}R_{t+n}+\gamma^n\bar V_{t+n-1}(S_{t+n}),\qquad t+n<T\)。

若 \(t+n\geq T\)，则 \(G_{t:t+n}\doteq G_t\)。其中，\(\bar V_t(s)\) 是时刻 \(t\) 在目标策略下，利用估计动作价值求得的状态 \(s\) 的期望近似价值：

公式（7.8）：\(\bar V_t(s)\doteq\sum_a\pi(a\mid s)Q_t(s,a),\qquad s\in\mathcal S\)。

在本书后面的许多动作价值方法中，都会用到期望近似价值。如果 \(s\) 是终止状态，则它的期望近似价值定义为 0。

## 7.3 n 步异策略学习

回想一下，异策略学习是在遵循一个策略 \(b\) 的同时，学习另一个策略 \(\pi\) 的价值函数。\(\pi\) 通常是相对于当前动作价值估计的贪心策略，而 \(b\) 是更具探索性的策略，例如 ε-贪心策略。要利用由 \(b\) 生成的数据，就必须根据两个策略选择已执行行动的相对概率，考虑两者的差异（见 5.5 节）。在 n 步方法中，回报跨越 n 步，因此我们关心的只是这 n 个行动的相对概率。例如，要构造 n 步 TD 的简单异策略版本，只需用 \(\rho_{t:t+n-1}\) 对时刻 \(t\) 的更新（实际上在时刻 \(t+n\) 执行）加权：

公式（7.9）：\(V_{t+n}(S_t)=V_{t+n-1}(S_t)+\alpha\rho_{t:t+n-1}\bigl[G_{t:t+n}-V_{t+n-1}(S_t)\bigr],\qquad0\leq t<T\)。

这里 \(\rho_{t:t+n-1}\) 称为重要性采样比率，表示在两个策略下选取从 \(A_t\) 到 \(A_{t+n-1}\) 这 n 个行动的相对概率（参见式 5.3）：

公式（7.10）：\(\rho_{t:h}\doteq\prod_{k=t}^{\min(h,T-1)}\frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)}\)。
