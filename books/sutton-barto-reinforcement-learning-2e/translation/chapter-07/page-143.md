公式：\(G_t\doteq R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots+\gamma^{T-t-1}R_T\)。

其中 \(T\) 是回合的最后一个时间步。我们称这个量为更新的目标。蒙特卡洛更新的目标是回报；一步更新的目标则是第一项奖励加上下一状态估计价值的折扣值，我们称之为一步回报：

公式：\(G_{t:t+1}\doteq R_{t+1}+\gamma V_t(S_{t+1})\)。

这里的 \(V_t:\mathcal S\to\mathbb R\) 是时刻 \(t\) 对 \(v_\pi\) 的估计。\(G_{t:t+1}\) 的下标表示，它是针对时刻 \(t\)、只采用截至时刻 \(t+1\) 的奖励的截断回报；折扣估计 \(\gamma V_t(S_{t+1})\) 代替了完整回报的其余项 \(\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots+\gamma^{T-t-1}R_T\)，正如上一章讨论的那样。现在要指出的是，这个思想在两步之后与在一步之后同样成立。两步更新的目标是两步回报：

公式：\(G_{t:t+2}\doteq R_{t+1}+\gamma R_{t+2}+\gamma^2V_{t+1}(S_{t+2})\)。

这里的 \(\gamma^2V_{t+1}(S_{t+2})\) 补上了未包含的 \(\gamma^2R_{t+3}+\gamma^3R_{t+4}+\cdots+\gamma^{T-t-1}R_T\)。类似地，任意 n 步更新的目标是 n 步回报：

公式（7.1）：\(G_{t:t+n}\doteq R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{n-1}R_{t+n}+\gamma^nV_{t+n-1}(S_{t+n})\)。

这里 \(n\geq1\)，\(0\leq t<T-n\)。所有 n 步回报都可以看作完整回报的近似：在 n 步后截断，再以 \(V_{t+n-1}(S_{t+n})\) 补上其余缺失的项。如果 \(t+n\geq T\)，即 n 步回报延伸到终止时刻或越过它，那么所有缺失项都视为零，n 步回报按定义等于通常的完整回报：\(G_{t:t+n}\doteq G_t\)。

注意，\(n>1\) 的 n 步回报涉及从 \(t\) 到 \(t+1\) 转移时尚不可得的未来奖励和状态。真实算法只有看到了 \(R_{t+n}\)，并计算出 \(V_{t+n-1}\) 之后，才能使用该回报；它们首次可得的时刻是 \(t+n\)。因此，使用 n 步回报学习状态价值的自然算法为：

公式（7.2）：\(V_{t+n}(S_t)\doteq V_{t+n-1}(S_t)+\alpha\bigl[G_{t:t+n}-V_{t+n-1}(S_t)\bigr],\qquad 0\leq t<T\)。

其他状态的价值保持不变：对所有 \(s\ne S_t\)，\(V_{t+n}(s)=V_{t+n-1}(s)\)。我们称这个算法为 n 步 TD。注意，每个回合的前 \(n-1\) 步完全不进行更新。为补足这些更新，回合终止后、下一个回合开始前，会额外进行同样数目的更新。完整伪代码见下一页方框。

**习题 7.1：**第 6 章指出，如果价值估计在时间步之间不变，蒙特卡洛误差可写成 TD 误差之和（6.6）。证明式（7.2）使用的 n 步误差也可写成 TD 误差之和（同样假定价值估计不变），从而推广前述结果。
