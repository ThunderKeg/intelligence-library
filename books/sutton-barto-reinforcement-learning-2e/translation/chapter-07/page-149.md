例如，如果某个行动在 \(\pi\) 下绝不会被选择，即 \(\pi(A_k\mid S_k)=0\)，那么 n 步回报的权重就应为零，完全忽略它。另一方面，如果偶然选到一个 \(\pi\) 选择概率远高于 \(b\) 的行动，这会提高原本赋予该回报的权重。这是合理的：这个行动是 \(\pi\) 的特征，因此我们想了解它；但 \(b\) 很少选择它，它也很少出现在数据中。为了弥补这种稀少性，行动出现时就必须赋予较高权重。注意，如果两个策略相同（同策略情形），重要性采样比率总是 1。因此，新更新式（7.9）概括了前面的 n 步 TD 更新，并可完全取代它。同样，前面的 n 步 Sarsa 更新也可以由一个简单的异策略形式完全取代：

公式（7.11）：\(Q_{t+n}(S_t,A_t)=Q_{t+n-1}(S_t,A_t)+\alpha\rho_{t+1:t+n}\bigl[G_{t:t+n}-Q_{t+n-1}(S_t,A_t)\bigr],\qquad0\leq t<T\)。

注意，这里的重要性采样比率与 n 步 TD（7.9）相比，起止时间都晚一步，因为此处更新的是状态—行动对。我们不需要关心先前选中该行动的概率有多大：它已经执行，现在就应该从随之发生的一切中充分学习；重要性采样只用于后续行动。完整算法的伪代码如下。

**算法：用于估计 \(Q\approx q_*\) 或 \(q_\pi\) 的异策略 n 步 Sarsa**

```text
输入：任意行为策略 b，且对所有 s ∈ 𝒮、a ∈ 𝒜 都有 b(a|s) > 0
对所有 s ∈ 𝒮、a ∈ 𝒜，任意初始化 Q(s,a)
把 π 初始化为相对于 Q 的贪心策略，或初始化为给定的固定策略
算法参数：步长 α ∈ (0,1]；正整数 n
所有对 Sₜ、Aₜ、Rₜ 的存取操作，都可以按模 n+1 的下标进行

对每个回合循环：
    初始化并存储非终止状态 S₀
    选择并存储行动 A₀ ~ b(·|S₀)
    T ← ∞
    对 t = 0,1,2,… 循环：
        如果 t < T：
            执行行动 Aₜ
            观察并存储下一奖励 Rₜ₊₁ 和下一状态 Sₜ₊₁
            如果 Sₜ₊₁ 是终止状态，则 T ← t+1
            否则，选择并存储行动 Aₜ₊₁ ~ b(·|Sₜ₊₁)
        τ ← t−n+1  （τ 是当前要更新其估计的时刻）
        如果 τ ≥ 0：
            ρ ← ∏ᵢ₌τ₊₁^min(τ+n,T−1) π(Aᵢ|Sᵢ)/b(Aᵢ|Sᵢ)  （ρτ+1:τ+n）
            G ← ∑ᵢ₌τ₊₁^min(τ+n,T) γⁱ⁻τ⁻¹Rᵢ
            如果 τ+n < T，则 G ← G + γⁿQ(Sτ₊ₙ,Aτ₊ₙ)  （Gτ:τ+n）
            Q(Sτ,Aτ) ← Q(Sτ,Aτ) + αρ[G−Q(Sτ,Aτ)]
            如果正在学习 π，则保证 π(·|Sτ) 相对于 Q 为贪心
    直到 τ = T−1
```
