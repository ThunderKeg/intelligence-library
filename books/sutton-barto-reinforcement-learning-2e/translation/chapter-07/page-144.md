**算法：用于估计 \(V\approx v_\pi\) 的 n 步 TD**

```text
输入：策略 π
算法参数：步长 α ∈ (0,1]；正整数 n
对所有 s ∈ 𝒮，任意初始化 V(s)
所有对 Sₜ 和 Rₜ 的存取操作，都可以按模 n+1 的下标进行

对每个回合循环：
    初始化并存储非终止状态 S₀
    T ← ∞
    对 t = 0,1,2,… 循环：
        如果 t < T：
            按 π(·|Sₜ) 选择行动
            观察并存储下一奖励 Rₜ₊₁ 和下一状态 Sₜ₊₁
            如果 Sₜ₊₁ 是终止状态，则 T ← t+1
        τ ← t−n+1  （τ 是当前要更新其状态价值估计的时刻）
        如果 τ ≥ 0：
            G ← ∑ᵢ₌τ₊₁^min(τ+n,T) γⁱ⁻τ⁻¹ Rᵢ
            如果 τ+n < T，则 G ← G + γⁿV(Sτ₊ₙ)  （Gτ:τ+n）
            V(Sτ) ← V(Sτ) + α[G−V(Sτ)]
    直到 τ = T−1
```

n 步回报用价值函数 \(V_{t+n-1}\) 补偿 \(R_{t+n}\) 之后缺失的奖励。n 步回报有一个重要性质：按最差状态的误差衡量，它们的期望一定比 \(V_{t+n-1}\) 更接近 \(v_\pi\)。也就是说，期望 n 步回报的最大误差，至多是 \(V_{t+n-1}\) 的最大误差的 \(\gamma^n\) 倍：

公式（7.3）：\(\max_s\left|\mathbb E_\pi[G_{t:t+n}\mid S_t=s]-v_\pi(s)\right|\leq\gamma^n\max_s\left|V_{t+n-1}(s)-v_\pi(s)\right|\)。

这对所有 \(n\geq1\) 成立，称为 n 步回报的误差缩减性质。由此可以形式化地证明，在适当的技术条件下，所有 n 步 TD 方法都收敛到正确的预测。因此，n 步 TD 方法构成一族可靠的方法，其两端分别是一步 TD 方法和蒙特卡洛方法。

**例 7.1：随机游走上的 n 步 TD 方法。**考虑把 n 步 TD 方法用于例 6.2（第 125 页）的五状态随机游走任务。假设第一个回合从中间状态 C 开始，一路向右，经过 D、E，然后在右侧终止，回报为 1。回想一下，所有状态的估计价值起初都是中间值 \(V(s)=0.5\)。根据这段经验，一步方法只会改变最后一个状态 E 的估计，使它朝观察到的回报 1 增加。两步方法则会改变终止前两个状态 D 和 E 的价值，使二者都朝 1 增加。三步方法，以及任意 \(n>2\) 的 n 步方法，都会使经过的三个状态 C、D、E 的价值朝 1 增加，而且增加的幅度相同。
