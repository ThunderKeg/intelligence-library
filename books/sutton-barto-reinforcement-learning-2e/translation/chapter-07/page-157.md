## 7.7 小结

本章发展了一系列时序差分学习方法，它们位于上一章的一步 TD 方法与再前一章的蒙特卡洛方法之间。采用中间程度自举的方法很重要，因为它们通常比任一极端表现得更好。

本章重点讨论 n 步方法：它们向前考察接下来的 n 项奖励、状态和行动。右侧的两幅四步备份图，合起来概括了本章介绍的大多数方法。左图的状态价值更新，是采用重要性采样的 n 步 TD；右图的动作价值更新，是概括了期望 Sarsa 和 Q-learning 的 n 步 Q(σ)。所有 n 步方法在更新前都要延迟 n 个时间步，因为只有到那时，所需的未来事件才全部可知。另一个缺点是每个时间步需要比前述方法更多计算。与一步方法相比，n 步方法还需要更多内存，记录最近 n 个时间步的状态、行动、奖励，有时还要记录其他变量。最终到第 12 章，我们会看到如何使用资格迹，以很少的内存和计算开销实现多步 TD 方法；但相对于一步方法，总会有一些额外计算。为了摆脱单个时间步的束缚，付出这些代价可能很值得。

![本章小结的四步备份图](assets/fig-7-summary.png)

图内文字译注：4-step TD＝四步 TD；4-step Q(σ)＝四步 Q(σ)；ρ＝异策略情形下的重要性采样比率；σ＝1 表示采样，σ＝0 表示求期望。左侧空心圆为状态、实心圆为行动；右侧最后一层分支表示对可能行动求期望。

虽然 n 步方法比使用资格迹的方法更复杂，但它们在概念上非常清楚，本章因此尝试利用这一优点，在 n 步情形下发展两种异策略学习方法。一种基于重要性采样，概念简单，却可能具有很高的方差。如果目标策略与行为策略差异很大，那么在这种方法变得高效、实用之前，大概还需要新的算法思想。另一种基于树备份更新，是 Q-learning 对随机目标策略的多步自然扩展。它不使用重要性采样；但如果目标策略和行为策略差异很大，即使 n 很大，自举实际跨越的也可能只有少数几步。
