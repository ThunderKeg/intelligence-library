**算法：用于估计 \(Q\approx q_*\) 或 \(q_\pi\) 的 n 步树备份**

```text
对所有 s ∈ 𝒮、a ∈ 𝒜，任意初始化 Q(s,a)
把 π 初始化为相对于 Q 的贪心策略，或初始化为给定的固定策略
算法参数：步长 α ∈ (0,1]；正整数 n
所有存取操作都可以按模 n+1 的下标进行

对每个回合循环：
    初始化并存储非终止状态 S₀
    根据 S₀ 任意选择行动 A₀，并存储 A₀
    T ← ∞
    对 t = 0,1,2,… 循环：
        如果 t < T：
            执行行动 Aₜ；观察并存储下一奖励 Rₜ₊₁ 和状态 Sₜ₊₁
            如果 Sₜ₊₁ 是终止状态，则 T ← t+1
            否则，根据 Sₜ₊₁ 任意选择行动 Aₜ₊₁，并存储 Aₜ₊₁
        τ ← t+1−n  （τ 是当前要更新其估计的时刻）
        如果 τ ≥ 0：
            如果 t+1 ≥ T，则 G ← R_T
            否则，G ← Rₜ₊₁ + γ∑ₐπ(a|Sₜ₊₁)Q(Sₜ₊₁,a)
            对 k 从 min(t,T−1) 递减至 τ+1：
                G ← Rₖ + γ∑ₐ≠Aₖπ(a|Sₖ)Q(Sₖ,a) + γπ(Aₖ|Sₖ)G
            Q(Sτ,Aτ) ← Q(Sτ,Aτ) + α[G−Q(Sτ,Aτ)]
            如果正在学习 π，则保证 π(·|Sτ) 相对于 Q 为贪心
    直到 τ = T−1
```

## 7.6 ＊统一算法：n 步 Q(σ)

到目前为止，本章考虑了三类动作价值算法，对应图 7.5 的前三个备份图。n 步 Sarsa 的转移全部取自样本；树备份算法中，所有从状态到行动的转移都充分展开分支，不进行采样；n 步期望 Sarsa 则除最后一个从状态到行动的转移充分展开、使用期望价值外，其余转移都取自样本。这些算法能够统一到什么程度？

图 7.5 的第四个备份图提示了一种统一思路：在每一步决定，是像 Sarsa 那样采样一个行动，还是像树备份更新那样考虑所有行动的期望。若每一步都采样，就得到 Sarsa；若从不采样，就得到树备份算法；若除最后一步外都采样，就得到期望 Sarsa。
