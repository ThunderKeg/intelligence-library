## 发现的问题

### F-01 · 印刷页 399：资格迹衰减速率的解释

- **原页证据**：PDF 物理页 421，在无条件性资格迹更新式后，正文写其以由 `λ^w` 控制的速率向零衰减；该更新式本身的乘数仍含 `γλ^w`。
- **初查现状**：译稿把正文中的速率也写成由 `γλ^w` 控制，混淆了原书的文字解释和公式。
- **复核**：译文已改为“以由 `λ^w` 控制的速率向零衰减”，更新式保持原样；正式 JSON 已重建。**已关闭。**

### F-02 · 印刷页 417：Miller 引文的 `definitive change`

- **原页证据**：PDF 物理页 439，引文结尾为 `accomplishes the definitive change in the appropriate synapses`，强调对相应突触完成最终、决定性的改变。
- **初查现状**：译稿写“发生确定性的改变”，容易读成 deterministic change。
- **复核**：现写“并使相应突触发生决定性改变”，与引文语义相符；正式 JSON 已同步。**已关闭。**

### F-03 · 印刷页 418：`AR−P` 算法缩写误作下标公式

- **原页证据**：PDF 物理页 440，联想奖励—惩罚算法及其单元使用正文缩写 `AR−P`，并在同段多次复现。
- **初查现状**：译稿写成 `A_{R-P}` 数学表达式，网页渲染为带下标的变量，改变了缩写形式。
- **复核**：同段全部改回 `AR−P`；正式 JSON 中无 `A_{R-P}` 数学片段，网页保留正文缩写。**已关闭。**

### F-04 · 印刷页 420：原书空白页的占位句

- **原页证据**：PDF 物理页 442 为空白页。
- **初查现状**：`page-420.md` 写“本页为空白页。”，这句话不是原书正文。旧构建器曾跳过该句，因此正式网页此前没有多出正文块。
- **复核**：源页现仅保留说明原页为空白的 HTML 注释，构建器的句子特判已移除；正式 JSON 最后一个阅读块在印刷页 419，未产生 p420 正文。**已关闭。**
