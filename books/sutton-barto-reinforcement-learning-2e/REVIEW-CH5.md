## 待修复问题

### 1. 与已审章节和术语表不一致的译法（中）

**位置与证据：**本章标题及正文用“蒙特卡罗”93 处；第 3 章第 58 页和第 8 章使用“蒙特卡洛”。本章“动作”108 处、“行动”仅 2 处；其中“动作价值”等复合术语应保留，但叙述单个 action 时，如第 91 页“状态、动作和奖励”、第 96 页“采取动作 a”，与 `TERMS.md` 的正文用“行动”不符。第 94 页正文和图片替代文字、第 97 页习题 5.3 把 *backup diagram* 译为“回溯图”共 4 处；第 3 章相同术语采用“备份图”，`TERMS.md` 也要求避免把 backup 译成“回溯”。

**建议：**本章统一成全书已用的“蒙特卡洛”；逐处区分独立叙述的 action 与“动作价值”等复合词，按术语表修订；第 94、97 页的 *backup diagram* 改为“备份图”，并同步图片替代文字。避免无条件全局替换“动作”，以免误改已约定的复合术语。

### 2. 正文仍有未进入数学排版的下划线记号（中）

**位置与证据：**第 92–94、96–103、105、107、110–111 页。排除已有 `\(...\)`、`\[...\]` 和 fenced code 后，可检出至少 54 处带 `_` 的原始记号。例如第 92 页 `v_π(s)`、`q_π`，第 97–98 页 `q_{π_k}`、`π_{k+1}`，第 105、107 页 `ρ_{t:T(t)−1}`，第 102 页 `v_{π′}`；部分算法框标题也显示 `v_π`、`π_*` 等原始下划线。桌面和 390px 深色阅读页实见这些记号原样显示，与已正确转换的编号公式观感不一，部分大括号还改变了下标的视觉范围。

**可靠检索：**先从各页 Markdown 中剔除三反引号代码块和 `\(...\)`／`\[...\]` 片段，再检索正则 `(?<!\\)[A-Za-zπρ]_(?:\{[^{}]+\}|[A-Za-z0-9πρ*])`；当前命中的页为 `92, 93, 94, 96, 97, 98, 99, 100, 101, 102, 103, 105, 107, 110, 111`。该扫描只查下划线，下标之外的行内数学仍需目视判断。建议将正文关键记号按原书写为 `\(...\)`，重打包并复核；算法框标题则需选择能被阅读器正确呈现的记法。代码框内为保持伪代码可复制，可沿用纯文本。
