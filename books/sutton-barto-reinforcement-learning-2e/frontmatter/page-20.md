# 记号表（续）

在马尔可夫决策过程中：

| 记号 | 含义 |
| --- | --- |
| s，s′ | 状态 |
| a | 一个动作 |
| r | 一次奖励 |
| 𝒮 | 所有非终止状态的集合 |
| 𝒮⁺ | 所有状态的集合，包括终止状态 |
| 𝒜(s) | 在状态 s 下所有可用动作的集合 |
| ℛ | 所有可能奖励的集合，是 ℝ 的有限子集 |
| ⊂ | 是……的子集，例如 ℛ ⊂ ℝ |
| ∈ | 属于，例如 s ∈ 𝒮、r ∈ ℛ |
| \|𝒮\| | 集合 𝒮 的元素数量 |

| 记号 | 含义 |
| --- | --- |
| t | 离散时间步 |
| T，T(t) | 一个回合的最后一个时间步，或包含时间步 t 的那个回合的最后一个时间步 |
| Aₜ | 时间 t 的动作 |
| Sₜ | 时间 t 的状态；通常在随机意义上由 Sₜ₋₁ 和 Aₜ₋₁ 导致 |
| Rₜ | 时间 t 的奖励；通常在随机意义上由 Sₜ₋₁ 和 Aₜ₋₁ 导致 |
| π | 策略（决策规则） |
| π(s) | 在确定性策略 π 下，状态 s 中采取的动作 |
| π(a∣s) | 在随机策略 π 下，状态 s 中采取动作 a 的概率 |

| 记号 | 含义 |
| --- | --- |
| Gₜ | 时间 t 之后的回报 |
| h | 前向视角中的视界，即向前看到的时间步 |
| \(G_{t:t+n}\)，\(G_{t:h}\) | 从 t + 1 到 t + n，或到 h 的 n 步回报（经过折扣和修正） |
| \(\bar G_{t:h}\) | 从 t + 1 到 h 的平坦回报（未折扣、未修正；第 5.8 节） |
| \(G_t^{\lambda}\) | λ 回报（第 12.1 节） |
| \(G_{t:h}^{\lambda}\) | 截断并修正的 λ 回报（第 12.3 节） |
| \(G_t^{\lambda s}\)，\(G_t^{\lambda a}\) | 分别用估计的状态价值或动作价值修正的 λ 回报（第 12.8 节） |

| 记号 | 含义 |
| --- | --- |
| p(s′, r∣s, a) | 从状态 s 采取动作 a 后转移到状态 s′ 并获得奖励 r 的概率 |
| p(s′∣s, a) | 从状态 s 采取动作 a 后转移到状态 s′ 的概率 |
| r(s, a) | 在状态 s 采取动作 a 后的期望即时奖励 |
| r(s, a, s′) | 在动作 a 下从 s 转移到 s′ 时的期望即时奖励 |

| 记号 | 含义 |
| --- | --- |
| \(v_\pi(s)\) | 策略 π 下状态 s 的价值（期望回报） |
| \(v_*(s)\) | 最优策略下状态 s 的价值 |
| \(q_\pi(s,a)\) | 在策略 π 下，在状态 s 采取动作 a 的价值 |
| \(q_*(s,a)\) | 在最优策略下，在状态 s 采取动作 a 的价值 |

| 记号 | 含义 |
| --- | --- |
| V，Vₜ | 状态价值函数 \(v_\pi\) 或 \(v_*\) 的数组形式估计 |
| Q，Qₜ | 动作价值函数 \(q_\pi\) 或 \(q_*\) 的数组形式估计 |
| V̄ₜ(s) | 期望的近似动作价值；例如 V̄ₜ(s) ≐ ∑ₐ π(a∣s)Qₜ(s, a) |
| Uₜ | 时间 t 的估计目标 |
