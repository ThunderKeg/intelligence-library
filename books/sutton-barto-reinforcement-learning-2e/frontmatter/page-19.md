# 记号表

大写字母表示随机变量，小写字母表示随机变量的取值和标量函数。必须取实数值的向量用粗体小写字母表示，即使它们是随机变量也是如此。矩阵用粗体大写字母表示。

| 记号 | 含义 |
| --- | --- |
| ≐ | 按定义成立的等式 |
| ≈ | 约等于 |
| ∝ | 正比于 |
| Pr{X = x} | 随机变量 X 取值 x 的概率 |
| X ∼ p | 随机变量 X 从分布 p(x) ≐ Pr{X = x} 中抽取 |
| 𝔼[X] | 随机变量 X 的期望，即 𝔼[X] ≐ ∑ₓ p(x)x |
| arg maxₐ f(a) | 使 f(a) 取得最大值的一个 a 值 |
| ln x | x 的自然对数 |
| eˣ，exp(x) | 自然对数的底 e ≈ 2.71828 的 x 次幂；eˡⁿ ˣ = x |
| ℝ | 实数集 |
| f : 𝒳 → 𝒴 | 将集合 𝒳 的元素映射到集合 𝒴 的元素的函数 f |
| ← | 赋值 |
| (a, b] | a 与 b 之间的实数区间，包含 b，不包含 a |

| 记号 | 含义 |
| --- | --- |
| ε | 在 ε-贪心策略中选取随机动作的概率 |
| α，β | 步长参数 |
| γ | 折扣率参数 |
| λ | 资格迹的衰减率参数 |
| \(\mathbb{1}_{\mathrm{predicate}}\) | 指示函数：如果命题 predicate 为真则等于 1，否则等于 0 |

在多臂赌博机问题中：

| 记号 | 含义 |
| --- | --- |
| k | 动作（臂）的数量 |
| t | 离散时间步或尝试次数 |
| \(q_*(a)\) | 动作 a 的真实价值（期望奖励） |
| Qₜ(a) | 在时间 t 对 \(q_*(a)\) 的估计 |
| Nₜ(a) | 在时间 t 以前选取动作 a 的次数 |
| Hₜ(a) | 在时间 t 学到的选取动作 a 的偏好 |
| πₜ(a) | 在时间 t 选取动作 a 的概率 |
| R̄ₜ | 在时间 t 对策略 πₜ 下期望奖励的估计 |
