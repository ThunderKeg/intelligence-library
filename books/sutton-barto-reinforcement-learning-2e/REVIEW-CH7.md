## 初审问题与修订复核

### F-01｜Q(σ) 伪代码把时间变量 t 错写成 τ（算法错误）

- 位置：page-156.md，离策略 n 步 Q(σ) 算法中初始化 \`G\` 的条件；原书印刷页 156（PDF 物理页 178）。
- 原书为 “If \`t + 1 < T\`: \`G ← Q(S_{t+1}, A_{t+1})\)”；译稿为“如果 \`τ+1 < T\`，则 \`G ← Q(Sₜ₊₁,Aₜ₊₁)\`”。
- \`τ=t-n+1\`，两种条件在回合尾部可能不同，会改变算法执行分支。应逐字校正为 \`t+1<T\`，并复核生成 JSON 与网页。
- 复核：**已关闭**。page-156.md 恢复 \`如果 t+1 < T\`，与原书物理页 178 的算法框一致；重建 JSON 和网页最后一个代码框也显示该条件。

### F-02｜五个算法框未构建为代码块，网页露出围栏标记

- 位置：page-144、147、149、154、156.md 的五个伪代码框；生成的 \`chapter-07.json\`。
- 源稿的代码围栏内部有空行，而当前 \`scripts/bundle_sutton_chapters.py\` 的 \`chunks()\` 按空行切块，将每个算法拆成普通段落。只读解析与已生成的 JSON 均为 **0 个 \`code\` 块**，另有 **10 个含三反引号围栏的普通段落**。
- 桌面网页截图在 7.6 节算法标题下直接显示 \`\`\`text，算法行被压成普通段落；手机端同样缺少可读的代码框。请协调修复构建器对代码围栏的解析，或规范源稿的围栏内容，再重建本章并验证五个算法框的层级、换行、缩进和窄屏横向滚动。此项也应避免影响其他章节的代码框。
- 复核：**已关闭**。构建器现保留围栏内部空行；重建 JSON 为 5 个 \`box\`、5 个 \`code\` 块，0 个残留围栏普通段落。网页独立检查桌面与 390px 深色模式均有 5 个算法框，换行和缩进保留；手机端代码区域 \`scrollWidth=539\`、\`clientWidth=293\`、\`overflow-x:auto\`，可横向查看完整代码，页面本身无横向溢出。已人工查看两种尺寸的算法截图。

### F-03｜式（7.13）与（7.17）的适用范围被扩大

- 位置：page-150.md 式（7.13）、page-155.md 式（7.17）；原书印刷页 150、下一页 156 顶部（PDF 物理页 172、178）。
- 原书两式后均写 \`t < h < T\`；译稿两处均写 \`t<h≤T\`。式（7.14）才写 \`t<h≤T\`，不可将其条件套到相邻公式上。
- 将（7.13）、（7.17）的限制恢复为严格小于 \`T\`；同时保留各式下方对 \`h=T\` 时终止递归的单独说明。
- 复核：**已关闭**。page-150 的（7.13）和 page-155 的（7.17）均为 \`t<h<T\`；原有终止说明保留。与 PDF 物理页 172、178 对照一致。

### F-04｜式（7.15）后条件句归属错位

- 位置：page-153.md，式（7.15）与两步树备份回报之间；原书印刷页 153（PDF 物理页 175）。
- 原书在一步式（7.15）后写 “for \`t<T-1\`, and the two-step tree-backup return is ...”，随后在两步公式之后写 “for \`t<T-2\`”。译稿却写成“当 \`t<T-1\` 时，两步树备份回报为”，使第一处条件落在两步公式上。
- 建议明确写成“式（7.15）适用于 \`t<T-1\`。两步树备份回报为……”，并将 \`t<T-2\` 明确附着于两步公式，再引出一般递归式。
- 复核：**已关闭**。page-153 现将 \`t<T-1\` 明确归于式（7.15），\`t<T-2\` 明确归于随后两步公式；顺序和原书物理页 175 一致。

### F-05｜式（7.17）后产生孤立标点段落

- 复核：**已关闭**。适用范围已纳入（7.17）的 TeX 公式；重建 JSON 不再有以逗号起头的独立段落，桌面及手机页面截图顺序正常。
