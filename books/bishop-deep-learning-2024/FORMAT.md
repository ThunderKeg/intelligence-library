# 本书的正文源文件格式

每章使用 `chapters/chapter-NN.md`；同一章由多人分节处理时，先在 `chapters/parts/` 写互不重叠的分稿，最后由集成 Agent 合并。原有 `translation/page-XX.md` 仅是待复核旧稿，不作为新的完成依据。

## 编写约定

- 用 `# 第 N 章 中文章名` 开始章节，用 `## N.N 中文节名` 和 `### N.N.N 中文小节名` 保留原书层级。包括章节开篇、练习和原书所有文字。
- 章标题后添加 `<aside class="chapter-guide"><strong>本章导读</strong><p>……</p></aside>`；只写简短导读，导读之外按原书翻译。
- 每遇到新 PDF 页面，写一个 `<!-- pdf-page: 物理页码 -->` 注释，便于逐页核对；注释不会显示在阅读页。
- 原书段落跨 PDF 页时，在新页标记后写 `<!-- join-previous-paragraph -->`，构建器会把其后的正文并入上一段，同时保留两个页码的追溯信息。
- 行内数学用 `$...$`，独立公式用 `$$...$$`，保留原书公式编号，例如 `\tag{1.1}`。不要用文字近似替代公式。
- 代码用带语言名的 Markdown 围栏，保持原书缩进与代码内容。表格用 Markdown 表格；复杂表格可写语义化 HTML 表格。
- 图像放在 `assets/chapter-NN/`，截取原书中的**单幅图**，不得使用整页截图。保留多子图关系和图中关键信息。正文中的图用下列 HTML；`src` 从站点根目录相对定位，并写准确 `alt`、原书编号、翻译后的图注。如图内有英文，在 `<p class="figure-translation">` 中逐项给出对应译文；如已在图片中重绘中文，则可省略这段。

```html
<figure id="fig-1-1">
  <img src="books/bishop-deep-learning-2024/assets/chapter-01/fig-1-1.png" alt="准确描述图片内容">
  <figcaption>图 1.1：准确翻译原书图注。</figcaption>
  <p class="figure-translation">图内文字：English → 中文；……</p>
</figure>
```

- 图片、公式、表格放在与原书一致的叙述位置。原书参考文献引用、脚注、习题编号与跨章引用须保留。保留难译英文术语并在首次出现处解释；同一术语全书保持同一译名。
- 不写编撰过程、授权声明或原书整页 PDF 嵌入。不得用“略”“待补”等占位符冒充完成内容。

## 验收

章节分稿需附一份独立核对记录，列出覆盖的 PDF 页、节、小节、图、表、公式、代码及待解决疑点。审查 Agent 对照原 PDF 后，方可更新 `TASKS.md` 中的完成状态。
