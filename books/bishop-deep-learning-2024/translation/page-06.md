## 1.2 一个教程示例

对机器学习初学者而言，可以借助一个简单的例子引入许多基本概念和术语：用多项式拟合一小组合成数据（Bishop，2006）。这是一种监督学习问题，我们希望根据输入变量的值预测目标变量。

### 1.2.1 合成数据

用 x 表示输入变量，用 t 表示目标变量，并假设两者都在实数轴上取连续值。设训练集包含 N 个 x 的观测值，记为 x₁，…，xₙ，以及相应的 t 的观测值 t₁，…，tₙ。我们的目标是根据某个新的 x 值预测 t。能够对以前未见过的输入做出准确预测，是机器学习的一个核心目标，称为泛化。

我们可以用一个从正弦函数采样生成的合成数据集来说明这一点。图 1.4 所示的训练集包含 N = 10 个数据点：输入值 xₙ（n = 1，…，N）在区间 [0, 1] 内均匀取值。对每个 x 值，先计算函数 sin(2πx)，再得到相应的目标数据值。
