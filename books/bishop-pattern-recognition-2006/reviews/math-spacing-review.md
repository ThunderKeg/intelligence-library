## 根因及修复范围

原 TeX 的 `\quad`、`\qquad` 等已编译成带 width 的 mspace；阅读器安全复制 MathML 时没有保留 width，造成原本用于分开并列定义或条件的空白消失。新增分支仅接受 `mspace` 节点上名为 `width`、值符合数字与 em/ex/px/pt/pc/cm/mm/in/% 单位白名单的属性，继续沿用原节点和属性过滤。此修复不替换符号、不修改 TeX 或 JSON。代码适用于阅读器 MathML，并非仅靠 CSS 改动间距。

分支允许带负号数值，但本书实际源 MathML 无负 width：独立 XML 清点为 **113 正宽、6 零宽、0 负宽、1 个无 width**。因此本次不声称验证了负间距的浏览器效果。C/D/E 连 mspace 节点都没有，新增分支对它们的公式无影响。第 8 章独立/不独立符号已由编译层合成为单符号，本次不撤销或替代该修复。

独立清单 `tmp/prml-review/math-spacing/source-space-inventory.json` 与 root 的 `reviews/math-spacing-qa.json` 一致。后者对有 width 的 15 个单元分别检查两模式：119 个节点每模式均与源值多重集合一致（共 238 次节点检查），所有正宽节点的实际矩形宽度大于零、页面不横向溢出、每个溢出的显示公式保留可见滚动提示。已审读 QA 实现；截图只覆盖各单元一个代表位置，节点守恒与宽度检查覆盖全单元，不把代表截图声称为每个间距的单独截图。
