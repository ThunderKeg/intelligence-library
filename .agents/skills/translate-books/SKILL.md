# 书籍翻译与编撰

完成 `{{ book_name }}` 的翻译和编撰。

## 工作要求

1. 对照原书逐章、逐节、逐段翻译，禁止凭印象补写或用概括替代正文。保留章节层级、段落、图表、图注、公式、代码、脚注、参考文献等全部内容；图片保留完整图形信息，图内文字也须翻译。文本提取仅辅助定位，仍须核对原页。
2. 保持代码和公式在网站上的准确、美观、可读、可复制，兼顾窄屏和深色模式。
3. 每章前增加简短、明确的中文导读，并与原书译文区分。
4. 难译的技术术语可以保留英文；重要术语首次出现时可采用“中文（English）”，全书译法保持统一。
5. 直译困难时可以适度意译，但须保证信达雅，不改变原意。
6. 避免抽象、空泛的表达，让具有一定背景知识的技术人员容易理解。
7. 正文中的交叉引用须保留原书编号，并支持点击跳转到对应的章节、小节、图表、公式等位置，跨章引用同样适用。

## 工作流程

1. 先按原书目录拆解任务，在本书目录维护任务清单，每完成一项就更新进展。沿用本书现有清单，新建时参考 [任务清单模板](assets/tasks-template.md)。
2. 按原书顺序逐章、逐节翻译。每完成一章，安排未承担该章初译的 Agent 逐句对照原书独立审查全部译文，并检查内容完整性、图表、公式、代码和网页排版；参考 [审查记录模板](assets/review-template.md) 记录问题，修复并复核后再标记完成。
3. 全部翻译完成后，再安排 Agent 做全书 review，检查跨章术语、符号、编号、引用、导读、目录和阅读体验，修复全局一致性问题。缺内容或审查问题未解决时保持未完成。

## 注意事项

- 多个 Agent 可能同时工作，按书、章或文件划分职责，避免覆盖其他 Agent 的编辑或使用可能回退他人工作的 Git 操作。
- 由当前 Agent 直接翻译，不使用本机模型。
